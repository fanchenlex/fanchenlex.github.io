JEPA-WAM: Learning Vision-Language-Action Policies with Joint-Embedding World Modeling

这篇工作把当前帧与未来帧联合编码成稠密的视觉转移目标，通过共享预测骨干，将世界建模监督传递到动作生成。它最值得作为后续 JEPA + memory + VLA 研究的复现起点：先确认预测监督究竟改善了什么，再研究持续记忆能补上哪些当前观测中缺失的信息。需要分清，联合转移表征不是显式状态差分，训练时的未来 token 也不是跨时刻记忆。

工作类型(首次/改进)技术路线创新点日期
改进V-JEPA + shared predictor + flow matching稠密联合转移目标 + 共享动作骨干监督2026-08-10

1.What？

JEPA-WAM 是一个在 V-JEPA 表征空间中学习视觉转移的 VLA。它不生成未来视频，而是让同一个 Transformer 骨干同时承担两项工作：在视觉 token 位置预测联合当前与未来的目标表征；在专门的动作占位 token 位置产生动作条件，再交给 flow-matching action expert。

论文包括两个设置，复现时必须分别看待：

设置 当前视觉路径 转移监督教师 主要定位
JEPA-WAM 基础模型 V-JEPA 2.1 ViT-L/16 + Qwen2.5-0.5B 冻结的 ViT-L/16 不依赖大规模机器人策略预训练
π0.5 + JEPA objective 保留 π0.5 原有感知、动作路径 冻结的 V-JEPA 2.1 ViT-G 为预训练策略增加辅助监督

2.Why？

视频生成式世界模型能够描述未来，但生成成本高，而且像素细节未必直接服务于控制。潜空间预测降低了成本，却仍有两个问题。

第一，预测什么？如果只预测经过全局池化的未来向量，细粒度物体位置与局部关系可能丢失。第二，预测损失如何帮助动作？如果预测器与动作骨干分离，世界模型学得好，并不保证策略真正获得了有用表征。

JEPA-WAM 的选择是：保留每个相机、每个 patch 的组织方式，用联合当前与未来的目标监督共享骨干，再从另一路 token 中提取动作条件。 它研究的是预测监督与策略表征之间的连接，不是在部署时对多组动作做世界模型搜索。

3.How？

左侧转移目标分支只在训练时使用；右侧动作专家接收共享骨干产生的动作条件。

3.1 当前视觉表征与联合转移目标

设第 v 路相机当前观测为 Otv ，冻结的编码器为 EJ 。当前视觉输入为

Zt=Concatv∈VEJ(Otv).

目标把当前帧和未来帧沿时间维度堆叠后联合编码：

Yt,t+δ=Concatv∈Vsg[EJ(Stacktime(Otv,Ot+δv))].

基础模型采用 384×384 输入、16×16 patch，每路相机得到 24×24 个 1024 维 token。V-JEPA 的 temporal tubelet size 为 2，两帧联合编码后仍对应同一个空间网格。监督按相机顺序和 patch 位置对齐，没有先做全局平均。

这里的 joint target 既不是单独编码未来帧，也不是 EJ(Ot+δ)−EJ(Ot) 。它携带当前与未来的联合时空关系，但仅凭这一构造，不能认定它已经获得了显式运动场、因果状态或可用于反事实动作比较的动力学模型。

3.2 共享骨干，分开提取预测与动作条件

视觉特征先经两层 MLP： 1024→896→896 ，映射至 Qwen2.5-0.5B 的 hidden space。骨干接收视觉、语言及 64 个 action placeholders。

视觉位置的输出 Qwm 经 896→2048→1024 的预测头回到教师空间；动作占位位置的输出形成 Ct ，供动作专家使用。动作专家是 16 层 DiT-L，另接收本体状态、32 个可学习 future tokens 和加噪动作。

这些 future tokens 是网络中的可学习序列参数，不是存储了过去 episode 状态的 memory bank。它们与 π0.5 扩展中的 64 个辅助查询也不是同一组设置。

3.3 训练目标与部署路径

转移损失为 patch-wise cosine distance：

Lwm=1N∑i=1N(1−Y^i⊤Yi∥Y^i∥2∥Yi∥2).

动作采用 flow matching。令 ϵ 为高斯噪声， a 为真实动作块：

aτ=(1−τ)ϵ+τa,Lact=E∥vϕ(aτ,τ;Ct)−(a−ϵ)∥22.

基础模型联合优化 Lact+0.5Lwm 。机器人训练阶段冻结视觉编码器、视觉 projector 与 Qwen 基础权重，更新 LoRA、转移预测头及动作专家；LoRA rank 为 32，scaling 为 64，dropout 为 0.1。

推理时不需要未来图像，移除目标编码和转移预测头，保留当前帧编码器、projector、共享骨干和动作专家。动作生成采用 4 步 Euler 积分。基础模型仍然需要当前帧 V-JEPA 编码，不能将“移除教师分支”理解成所有 V-JEPA 计算都消失。

3.4 π0.5 扩展的关键细节

该版本在 VLM prefix 中加入 64 个查询，将其组织为 8×8 网格，经过 2048→2048→1408 的预测头，再双线性上采样到 24×24，对齐 ViT-G 教师目标。辅助损失权重在前 1K 步从 0 线性增加到 0.1。

最关键的是 attention mask：新增查询可以读取原来的图像、语言 prefix，但原有动作 token 不能读取新增查询。 因而收益通过共享权重上的监督传递，不能解释为动作专家在直接读取预测出的未来特征。

附录还明确说明：推理时教师、预测头和损失移除，新增查询仍保留在 prefix，动作路径上的 mask 仍有效。所以也不应写成“所有新增 token 都在推理时删除”。

3.5 复现时需要固定的设置

项目 LIBERO RoboTwin 2.0
基础模型相机输入 主视角 + 腕部视角 主视角 + 两路腕部视角
动作 horizon 8 50
未来目标间隔 δ 31 50
轨迹边界 未来帧截断到最后一帧 同左

基础模型的 LIBERO 训练配置为 8 GPU、总 batch size 128、60K 步。LIBERO-Plus 直接测试在 LIBERO demonstrations 上训练的策略，不使用 OOD 数据额外微调。复现 π0.5 扩展时，应读取其对应训练配置，不能沿用基础模型的所有超参数。

4.实验结果

4.1 预测监督带来了什么？

下表汇总原文 Tables 1–3 的平均成功率，单位为 %：

方法 LIBERO LIBERO-Plus RoboTwin Clean RoboTwin Random
JEPA-WAM，无机器人策略预训练 96.7 79.2 79.9 36.9
π0.5 96.9 84.5 75.4 37.2
π0.5 + JEPA objective 97.8 86.3 84.6 37.5

π0.5 扩展在 LIBERO-Plus 提升 1.8 个百分点，在 RoboTwin Clean 提升 9.2 个百分点，但 Random 仅提升 0.3 个百分点。结果支持预测监督有效，却不足以说明它已经普遍解决了所有分布偏移。RoboTwin 平均值覆盖 20 个任务，不能用表中展示的少量任务自行重算。

4.2 必须区分 encoder 收益与预测目标收益

原文 LIBERO-Plus 消融给出：

设置 平均成功率 / %
DINOv2 + SigLIP，无转移预测 73.2
仅替换为 V-JEPA 表征 77.0
V-JEPA + future-only target 77.3
iREPA 卷积目标 74.7
对齐中间层的 lower-16 设置 76.5
将完整预测 hidden states 用作动作条件 73.1
完整 JEPA-WAM 79.2

从 73.2 到 77.0 的变化首先来自视觉表征替换，不能都归功于 JEPA 预测损失。联合目标相对 future-only 的增益，以及专门动作条件优于直接使用完整预测 hidden states，才更直接支持论文的目标设计和路径设计。

5.Takeaways:

5.1 对后续 JEPA + memory + VLA 的意义

我把它作为优先复现基线，原因是它直接对应“先在 π0.5 上稳定得到预测监督收益，再添加记忆”的路线。它留下的明确缺口是：每次决策依然从当前观测出发，没有显式跨步维护已发生事件、消失物体位置和任务阶段。

后续应回答的具体问题是：当当前图像不足以确定下一步动作时，记忆能否让联合转移预测更准确，并让策略选择更正确的动作？ 只增加一个 memory 模块后成功率上涨，无法说明这两个环节之间存在因果联系。

以下属于后续研究设计，尚未由原论文验证：

  1. 固定 π0.5 初始化、训练数据、步数和评测协议，构建“有／无预测监督 × 有／无记忆”的四组对照，检验两者是否存在协同。
  2. 分别让记忆进入预测分支、动作分支以及两者，明确收益经过哪条路径传递；同时报告参数量、token 数、延迟和历史长度。
  3. 对相同当前观测替换、删除历史，检查动作与预测是否随真正相关的历史证据改变。LIBERO-Plus 检查视觉鲁棒性，RoboDojo 检查需要历史的决策，两个目标应分别统计。
  4. 用预测误差驱动记忆更新前，区分物体状态变化、腕部相机运动、遮挡和背景扰动，避免把“难预测”直接等同于“值得长期保存”。

5.2 局限性 & 未来工作

稠密 patch 对齐保留了空间组织，但没有直接保证对象身份、任务阶段或语言条件下的转移语义。低预测误差也不必然意味着长程任务所需的信息被保留。

这篇论文最重要的启发是用可控的预测目标塑造动作表征；后续记忆研究则需要证明：保存的信息恰好弥补了部分可观测性，而不是单纯增加上下文和模型容量。
