Slot-JEPA: Object-Structured Prediction Interfaces for Latent World Models

这篇工作把稠密 JEPA 特征拆成共享语义 slots 与随时间变化的空间 masks，使历史转移能够被紧凑存储和按需检索，再通过非平衡最优传输评价预测离视觉目标还有多远。对 JEPA + VLA + Memory 方向，真正值得借鉴的是表示、记忆和目标度量共用一套对齐接口，而不是单独把 patch tokens 换成 slots。

1.What？

Slot-JEPA 是面向视觉目标条件规划的潜在世界模型。它在 V-JEPA 2.1 编码器与任务动力学预测器之间，加入一套预训练的 slot decomposition 接口，然后用 Transition Memory Predictor（TMP）读取历史状态—动作—下一状态转移，预测给定动作下的下一时刻 masks。

部署时，MPC 使用模型想象动作后果，CEM 搜索动作序列，并以预测 masks 到目标 masks 的距离排序。它不是语言指令到动作的 VLA，实验也没有证明开放词汇指令跟随或跨机器人通用策略。

部分 作用 下游控制阶段
视觉编码器 E 提取稠密 patch 特征 冻结
Slot decomposition 提取共享 slots、解码空间 masks 模块参数冻结；运行时 slot bank 由参考图像提取
TMP 与任务状态／动作编码器 从历史转移预测动作后果 在任务数据上微调；推理读取观测记忆
Transition memory bank 保存已观测到的转移 新观测到达后追加；slot 刷新时重新解码
UOT + mask 距离 监督预测并评价视觉目标进度 为 CEM/MPC 提供规划代价

这是一种显式转移记忆，不是 test-time gradient training。推理期间新增观测改变记忆内容，并不表示在线反向传播更新 TMP 参数。

2.Why？

2.1 Patch 特征对感知有用，却不一定是最佳动力学接口

一个物体分散在许多 patch 中，预测器需要自己恢复物体组织和交互关系；历史也由高维稠密场组成，存储和逐帧比较开销大。如果每个任务预测器都重新完成对象组织，预训练表示中的结构没有被显式复用。

另一个问题是目标距离。两个局部 mask 完全不重叠时，逐点 L1 可能主要取决于总面积，而无法充分区分相隔近与相隔远。于是一个预测器即使没有很大误差，规划器仍可能拿不到反映空间进度的信号。

论文同时处理三个耦合问题：用什么状态表示、从哪些历史转移学习当前变化，以及怎样给想象出来的未来打分。

3.How？

3.1 稳定语义 slots + 动态空间 masks

视觉特征为 Z∈RT×N×D ，参考帧提取共享 slots S={sk}k=1K 。同一环境中，各帧特征在共同基底下解码成 M∈[0,1]T×K×N ，以加权混合重建：

Z¯t,n=∑k=1Kmt,k,nsk.

slot 表达共享内容，mask 表达其在当前图像中的位置与分配。不是每帧重新生成一套无对应关系的对象向量，再直接比较不同编号的 slot。

接口使用局部到全局的 Slot Attention：参考特征分窗，局部 slots 竞争聚合，最远点采样初始化全局 slots，再全局聚合；默认 K=16 。mask decoder 将 patch 特征作为 query 访问 slots，再通过 MLP 和跨 slot softmax 产生 mask。

分解损失包含特征 L1 重建与 slot 正交约束。这里重建的是预训练语义特征，不是 RGB；无实例或部件标注，所以不能保证一 slot 对应一个物理对象。背景、多物体合并和物体部件都能成为 slot。

3.2 压缩了什么，以及没有压缩什么？

稠密特征需 TND 个标量，分解后为 KD+TKN 。共享 slots 的成本在较长序列中被摊薄，逐帧主要存 KN 个 mask 数值。论文给出 K=16 时约 2.5% 的表示标量规模。

这一比例描述表示存储，不是端到端延迟、GPU 峰值显存或模型参数减少 97.5%。记忆仍需保存转移的状态与动作，slot bank 刷新还要重新解码保留帧；这些成本不能由标量比例直接推导。

3.3 TMP 保存完整转移，检索相关而多样的历史

同一 slot bank 对齐的记忆条目为：

Bt={(Mi,ri,ai,Mi+1,ri+1)}.

其中 ri 为可用的低维状态，包含机器人位姿等信息。记忆并非只有一张历史 mask，它还包括当时动作以及实际下一状态。

检索摘要组合归一化低维状态、每个 slot 的面积与二维质心。沿用原文记号，令这些统计为 ρi,μi ：

ui=[ri‖λvρi‖λvμi],dmem(t,i)=∥ut−ui∥22.

采样概率混合距离相关性和均匀探索：

Pt(i)=(1−γ)softmaxi(−dmem(t,i))+γ|Bt|.

每次不放回采样五条转移；平面规划附录进一步限定在最近邻的 50 条转移中采样。不能把这一额外限制直接套到所有环境。

相关性让模型读到相似状态，多样性避免全是局部重复。采样集在同次规划请求的不同动作方案之间保持一致，减少“换动作时也换历史”造成的代价噪声。

面积与质心仍是有限的摘要：物体旋转、接触变化或外观变化不一定体现在这些统计中。论文也将检索遗漏和冗余列为局限。

3.4 双分支预测：单 slot 空间动态与跨 slot 交互

TMP 把已知转移组织成 context blocks，把当前状态与待评估动作组织成 query block。历史块包含真实 source 和 target；query 中未知的未来状态及空间场由可学习 tokens 占位，推理不会读取真实未来。

mask branch 对每个 slot 的空间场 mi,k,nsk 建模，使用多尺度预测；feature branch 读取重建特征与 masks，建模多个 slots 之间的共享交互。两分支融合后，经跨 slot softmax 输出 M^t+1 。

其优势在于把每个区域怎样移动，与对象之间怎样相互影响交给不同计算路径。共享 feature branch 仍处理空间特征，因此不能把模型描述成全程只有 16 个 tokens 的轻量 Transformer。

3.5 无动作视频预训练：伪动作是训练瓶颈

Kinetics-400 没有机器人动作标签，原文使用 inverse transition encoder 将已观测的源、目标 masks 与 slots 压缩成低维伪动作。目标的信息通过这个瓶颈传给预测器，而非完整目标场直接进入 query。

每段七帧提供四个已观测帧与三个预测目标，包含正向和反向训练。**预训练 context 来自当前采样片段，不维护或检索跨片段持久记忆库。**这与部署时持续追加转移的记忆机制应当区分。

预训练后，inverse transition/state encoders 被丢弃，替换成任务专用的实际状态与动作编码器，迁移并微调 TMP。不能将训练时利用目标的逆编码器直接搬到在线推理中。

训练起点是蒸馏 V-JEPA 2.1 ViT-B/16；预训练时微调视觉编码器最后六个 blocks，其余冻结，联合训练分解模块、TMP 和逆编码器。下游才冻结整个视觉编码器与分解模块。论文报告八张 RTX 4090、10 epochs、约 30 小时；这不包含基础模型原有的大规模预训练成本。

3.6 UOT：在同一 slot 内衡量空间移动

预测和目标 masks 都在同一 S 下解码，编号对应。对一对非负 masks p,q ，patch 间基本空间代价为：

Cij=∥ξi−ξj∥22.

用非负传输矩阵 π 表示从位置 i 向 j 搬运的质量，熵正则帮助求解，KL 边缘惩罚允许质量增减：

π∗=arg⁡minπ≥0⟨π,C⟩+εΩ(π)+ρKL(π1‖p)+ρKL(π⊤1‖q).

这里 ρ 是 UOT 的质量变化惩罚，与前面记忆摘要中的 slot 面积向量是不同用途。原文用 Sinkhorn scaling 求近似解，再在解上评价传输与质量变化两项：最终评价式不包含显式熵项。

mask 不做面积归一化，也不要求两端总质量相同。这适合视角、遮挡、尺度和分解误差导致面积变化的情况；它不是物理质量守恒或可靠的对象永久性证明。

训练联合使用 UOT、mask L1 与重建特征 L1：

Lpred=λuot∑kTε,ρ(m^k,mk)+λmask∥M^−M∥1+λfeat∥Z^−Z∥1.

规划用前两项对视觉目标打分。附录还根据参考与目标 mask 的变化加权，降低静态背景主导；权重来自已观测或目标 masks，而非模型预测。

在 TwoRoom/Maze 及其变体中，静态 slots 形成障碍图并修改 ground cost；PushT/PushObj 与机械臂使用普通空间代价。因此，平面任务的绕障能力还利用了这一显式几何处理，不能全部解释为预测器自动学会碰撞规划。

3.7 记忆初始化、slot 刷新与多视角协议

设置 slot 来源 初始转移记忆
平面 ID 部分训练轨迹提取的固定 bank 随机采样训练转移
平面 OOD 同一固定 slot bank 新布局／新形状中先执行随机动作
REALM-JEPA 初始图像、给定目标图像与随机 warmup 观测 warmup 中实际观测到的转移

目标图像允许参与机械臂 slot 提取，但不提供目标前后的真实动作转移；评估 rollout 的未来帧不参与初始化。随机探索发生在正式目标规划前，是可用交互条件，不能把结果称作无历史、无 warmup 的零交互泛化。

slot bank 在扩展 rollout 后可以刷新，保留转移须重新解码，保证编号一致。附录没有给出固定刷新周期，复现时需从实现继续核对。

机械臂三视角共享预测器参数，分别维护 slots、记忆和预测，没有 TMP 内部的跨视角注意力或统一记忆库。CEM 先用两固定相机的平均代价优化分布，再由腕部相机继续优化；不是简单平均三路代价一次选动作。

4.3 规划代价是否反映真实进度？

原文 Table 4 不只看成功率，还比较观测／预测代价与实际七维末端状态到目标的距离。三个视角中，Slot-JEPA 的观测代价相关系数为 0.792、0.891、0.807；V-JEPA 2.1 对应为 0.350、0.407、0.533。

这支持更合理的目标度量，而不是把全部失败归因于未来预测误差。统计在任务内标准化、按距离分层采样后进行任务宏平均；七维状态距离与用于辅助 baseline 的三维 30 cm 阈值是两个不同量。

近期上下文与完整模型在 PushObj 同为 58%；顺序预测器在 TwoRoomR 为 94%，高于完整模型的 90%。所以不能声称 TMP 在每个环境都优于所有变体。更明确的模式是复杂任务需要多样历史，而 OOD 布局对检索相关性敏感：随机转移在 TwoRoomR 只有 40%。

4.5 感知信息是否保留？

Table 1 的七个感知 benchmark 中，Slot-JEPA 相对 V-JEPA 2.1 的 COCO/ADE/VOC mIoU 从 52.8/35.5/72.1 增到 56.1/38.9/75.1；DAVIS J&F 从 65.9 到 66.6，KITTI 深度指标则从 89.2 降到 87.8。

这说明对象化接口保留了多项有用语义，没有证明所有感知能力都提高。预训练还微调了最后六层视觉编码器，因此应将变化视为整套预训练与接口设计的共同结果，而非纯压缩后的无损保证。

5.Takeaways:

5.1 对研究方向的判断

Slot-JEPA 最贴近 JEPA + Memory 的部分，是让历史转移、未来预测和目标比较共享有编号对应的空间接口。TMP 读的是“在相似状态下执行动作后发生了什么”，因此比只保存历史图像更接近可复用的交互经验。

但它没有直接解决长期身份记忆。固定 slot bank 的稳定性是当前上下文内的表征对齐，不是跨任务统一身份；实例混合、遮挡和 slot 刷新依然可能损伤绑定。规划使用的可见区域 mask，也不能自动代表隐藏对象的完整状态。

5.2 与 EvoMem-VLA、T²Mem 的关系

工作 历史接口 未来或动作出口 最直接可借鉴的部分
EvoMem-VLA 状态与变化 tokens 动作／子任务 显式保存交互进度证据
Slot-JEPA 对齐 masks 的状态—动作转移 未来 masks + 视觉目标规划 转移检索与空间目标度量
T²Mem episode 快速权重 VLA 动作 动作监督塑造读写机制与记忆干预

这三条路线可以联系，但不能直接把模块拼接当成研究结论。先确定目标是进度记忆、状态估计还是动作后果预测，再选择相应表示与评价。

5.3 后续实验：把“记住变化”与“预测变化”接起来

以下属于研究设计，原文没有给出对应结果：

  1. **接口对照。**固定预训练 encoder 与 VLA，比较 patch 状态记忆、slot 状态记忆、显式变化记忆和带动作的 slot 转移记忆。让帧数、训练预算与可读历史长度一致，并分别报告 token／存储成本。
  2. **监督对照。**比较动作监督、JEPA 预测监督与联合目标，检查预测改善是否真的提升遮挡后的动作决策。不能把较低重建误差当作记忆正确的充分证据。
  3. **检索干预。**比较近期、随机、面积／质心、对象状态与动作相关检索；用错误动作后果替换真实转移，检查策略是否区分“相同源状态、不同后果”。
  4. **一致性压力测试。**加入相似物体互换、移出视野后返回、位姿复位但计数变化，以及重新提取 slots。同步测 slot 对应漂移、阶段判断和最终成功率。
  5. **交互预算控制。**单独报告无 warmup、等预算随机 warmup 与任务引导 warmup；统计初始化时间和正式任务耗时，避免用更丰富历史换取未注明的性能增益。

对当前项目，先做“在同一 VLA 上增加动作相关转移记忆”的小规模受控验证，比同时重训视觉 encoder、换策略主干并引入 CEM 更容易得到可解释的结果。

5.4 局限与复现重点

slots 没有实例真值保证，检索统计不能完整描述接触与外观，记忆追加也没有给出严格有界容量方案。slot 刷新依赖保留帧重新解码，长时程成本需要测量。UOT 的二维空间距离与真实三维可执行性也不同，普通 UOT 不自动保证机械臂避碰。

论文未给出足以比较实际机器人控制实时性的端到端延迟；压缩比例不替代 CEM、多视角预测、Sinkhorn 和 warmup 的整体耗时评估。机械臂结果需要进一步在真实执行、更多场景和重复随机种子上验证。

5.5 组会三分钟总结

Slot-JEPA 认为 JEPA 的稠密特征虽然语义强，却把对象组织、历史对应和空间目标度量都留给了下游。它将特征分解为共享语义 slots 与变化 masks，用 TMP 检索状态—动作—下一状态转移，再以 UOT 衡量对象区域离目标还有多远。六个平面环境与 REALM-JEPA 108 个仿真实例支持这套设计；机械臂成功率从 V-JEPA 2.1 的 35.2%，经 TMP 的 58.3%，到完整系统的 86.1%。需要保留的条件是随机探索初始化、阶段视觉目标和仿真评估；slots 也不保证物理实例身份。对我的研究，最值得迁移的是对象对齐的转移记忆与动作相关未来预测，再通过同一 VLA 的受控实验检验它们能否改善记忆依赖控制。
