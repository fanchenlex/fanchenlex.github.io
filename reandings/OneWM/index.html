OneWM: Can World and Action Modeling Benefit Each Other under Unified Causal Training?

OneWM 把世界预测和动作生成放进同一个因果视频—动作模型。训练时，一部分样本给定干净动作，学习动作后的视觉变化；另一部分样本要求模型从噪声生成动作。论文分别比较两种能力，检验这种联合训练能否同时改善控制和预测。

1.What？

OneWM（原文题目为 Can World and Action Modeling Benefit Each Other under Unified Causal Training?）使用两个专家：

  • Video expert：在 VAE 潜空间中预测未来视频。
  • Action expert：在动作块上做 flow matching，生成控制动作。

两条路径共享因果联合注意力，但保留各自的投影层和前馈层。视频和动作都接收同一条语言指令，不过通过各自的文本交叉注意力进入模型。

训练时，动作有三种身份：

训练方式 动作输入 主要学习目标
All-clean 整个动作块都是示范中的干净动作 学习指定动作会怎样改变画面
Partial-clean 前缀是干净动作，后缀带噪 一边利用已知动作条件，一边生成剩余动作
All-noisy 整个动作块带噪 从视觉和指令生成完整动作

默认采样概率按 All-noisy / Partial-clean / All-clean 排列为 60% / 25% / 15%，每个样本单独选择训练方式，同一批次混合训练。

2.Why？

普通动作策略主要学习：

看到当前画面和指令，应该输出什么动作？

世界模型主要学习：

当前画面下，如果执行某个动作，之后会发生什么？

两者学的是同一段交互的两面。问题在于，很多联合模型虽然同时处理视频和动作，但视频分支看到的动作一直是带噪变量，或者根本看不到动作。这样得到的视频预测未必真正学会了“这个具体动作造成了什么结果”。

OneWM 把两种情况拆开：

  1. 让视频分支看到干净动作，明确学习前向动力学。
  2. 让动作分支从噪声中恢复动作，保持真正的策略学习。
  3. 在两种训练之间加入部分干净的过渡，而不是只训练两个互不相干的模型。

这里的“互惠”首先指共享参数和注意力中的监督互相影响。它不等于已经证明世界模型在部署时进行规划，也不等于生成的视频一定是物理上正确的。

3.How？

3.1 两个专家如何交流？

设已观测视觉上下文为 V0 ，第 i 个未来视频潜帧的 token 为 Vi ，与它对齐的动作段为 Ai 。原文式（2）给出两类查询可见的 key：

Sv(i)=V≤i∪A≤i,Sa(i)=V0∪A≤i.

V≤i 包含从观测上下文到第 i 个未来潜帧的 token， A≤i 包含截至第 i 段的动作 token。

  • 未来视频查询可以读取截至当前块的视频与动作，包括当前块内部的信息。
  • 动作查询只能读取已观测视觉上下文和截至当前块的动作，不能读取未来视频。
  • 观测上下文的查询只在观测流内部交互。

两个专家分别计算自己的 Q、K、V，再按照上述 mask 做联合注意力；输出投影和前馈层也各自保留。这里的“因果”落实在时间可见性上，同一视频潜帧或动作段内部仍允许自由交互。

这一点也解释了为什么部署策略可以省去未来视频生成：动作路径本来就不依赖未来视频 token。世界预测损失是在训练时通过相连的专家影响策略表征。

3.2 三种动作条件

动作块长度为 K ，前 r 个动作保持干净，后缀加噪。原文式（4）为：

ak(r,τ)={ak,k≤r,a~k(τ),k>r.

a~k(τ) 是噪声等级 τ 下的动作。干净前缀的噪声等级嵌入为 0，带噪后缀使用同一个采样噪声等级。模型由此区分已知条件和去噪目标。

All-clean： r=K 。 整段示范动作保持干净，仅监督未来视频预测，没有动作去噪损失。学习的是给定观测、指令和动作后，未来视频潜变量的条件分布：

pθ(zfut∣zctx,ℓ,a).

Partial-clean： 0<r<K 。 干净动作前缀既参与视频预测，也帮助生成动作后缀；动作损失只计算带噪后缀。论文混合两种前缀长度采样方式：一种在视频对齐动作段的边界附近扰动至多两个动作步，并截断到 1 至 K−1 ；另一种在这个范围内均匀采样。正文没有给出这两种方式的具体混合比例。

All-noisy： r=0 。 整段动作都是去噪目标。模型从当前观测和指令生成完整动作块，视频分支在训练中读取带噪动作特征。

三种设置一直使用同一套注意力可见性规则，变化的是哪些动作保持干净、哪些动作需要预测。观测视频前缀始终干净，未来视频潜变量始终接受去噪监督。

3.3 训练目标

视频和动作都采用 flow matching。原文使用的插值方向是：

x(τ)=(1−τ)x+τϵ,ϵ∼N(0,I).

因此 τ=0 对应干净数据， τ=1 对应高斯噪声，监督的速度为 ϵ−x ；采样沿 τ=1→0 积分。

总损失为：

L=λvLv+λaLa.
  • Lv ：未来视频潜变量的加权速度预测均方误差。
  • La ：仅在带噪动作后缀上计算的加权速度预测均方误差。
  • All-clean 样本不提供动作去噪目标。

视频和动作的噪声等级独立采样。两项损失通过因果联合注意力训练相连的专家，使指定动作后的预测监督与动作生成监督作用于同一模型。

4.部署时究竟使用哪条路径？

执行机器人策略时，无需先生成未来视频。

给定当前观测和指令，Action expert 从高斯噪声开始，逐步生成动作块：

a^∼pθ(a∣zctx,ℓ).

观测视频表征在各个动作去噪步骤之间复用。闭环控制每次重规划时读取最新观测，生成下一段动作。

世界预测模式固定指定的干净动作块，Video expert 从高斯噪声生成未来视频潜变量，再由 VAE 解码成画面。

这两个模式共用模型，使用时可以分别调用。论文中的策略收益主要来自训练阶段的联合监督，不能据此认定部署时进行了基于未来视频的规划。

5.实验：世界预测真的帮助了动作策略吗？

内部比较使用同一个因果架构：

模型 视频能否读取动作 是否有干净动作条件训练
WAM_mask 不能 没有
WAM_noisy 可以，但动作始终带噪 没有
OneWM 可以，按时间因果读取 有

策略成功率如下：

方法 LIBERO LIBERO-Plus RoboCasa365
WAM_mask 92.45% 53.37% 28.32%
WAM_noisy 92.60% 52.50% 未报告
OneWM 94.95% 59.27% 36.68%

OneWM 在 LIBERO-Plus 的背景、相机、语言、布局和传感器噪声扰动下整体更强，但光照扰动下并非最好。因此更准确的说法是：在这些测试设置中，干净动作条件训练改善了泛化；它没有解决所有分布变化。

真实机器人包含三类任务：

  • 积木堆叠；
  • 积木插入；
  • 早餐摆放。

每项任务采集 50 条示范，每个模型每项任务测试 15 次。OneWM 的成功率高于 WAM_mask，但任务数量和测试规模仍然有限。

6.动作学习反过来帮助世界预测吗？

这里比较 OneWM 与 WM：

  • WM：只做给定干净动作后的未来视频预测。
  • OneWM：同时训练视频预测和动作生成。

两者在推理时都接收干净动作块，因此这个比较主要检查动作生成目标本身有没有帮助世界预测。

基准 WM PSNR OneWM PSNR WM SSIM OneWM SSIM WM LPIPS OneWM LPIPS
LIBERO 22.33 22.95 0.8325 0.8423 0.1529 0.1458
LIBERO-Plus 20.54 21.05 0.7937 0.8049 0.2014 0.1935
RoboCasa365 24.72 25.21 0.8433 0.8515 0.1087 0.1015

这组结果支持一个直观解释：

为了生成正确动作，模型必须关注机器人、物体和场景之间与控制有关的关系；这些关系也能帮助它预测指定动作之后的画面。

但 FID 和 FVD 的排名并不完全一样。单纯的分布指标不能说明预测是否真的遵循了输入动作，所以评价动作条件世界模型时，仍需要逐条对应的未来画面指标。

7.动作条件比例为什么重要？

论文比较了三种比例：

All-noisy / Partial-clean / All-clean LIBERO LIBERO-Plus
60 / 25 / 15 94.95% 59.27%
50 / 35 / 15 95.95% 56.98%
30 / 45 / 25 87.80% 38.01%

如果大幅增加干净条件和 Partial-clean 的比例，视频预测指标没有明显恶化，但策略泛化下降，尤其是 LIBERO-Plus。

论文将这一现象与训练、部署条件的对应关系联系起来：部署需要从噪声生成动作，因此必须保留足够的 All-noisy 训练。这里同时改变了多种训练方式的比例，仅凭这三组结果还不能独立确定每一种方式的贡献。

所以 60 / 25 / 15 是论文测试中比较平衡的设置，不是通用最优答案。

8.Endless Dream：把两个模式串起来

论文还展示了一个无需额外训练的想象循环：

  1. 根据当前视觉上下文和指令生成动作块。
  2. 将生成动作固定为干净条件，预测未来视频。
  3. 取各路相机最后一帧预测，作为下一轮的视觉上下文。
  4. 保持指令不变，重复上述过程。

LIBERO 展示运行 16 轮，每轮生成 32 个动作和 8 帧未来画面，总计 512 个动作，对应 25.6 秒的建模时长。只有初始图像来自环境，后续全部来自模型预测；25.6 秒也不是生成这些内容的实际耗时。

这说明两种能力能够组成任务导向的想象轨迹。论文没有用这一展示证明真实环境任务成功率，也没有验证把想象轨迹接入规划或策略优化后能带来多少收益。

9.视频笔记中关于 memory 的讨论

以下讨论依据我整理的视频笔记，和论文中的实验结果分开记录。

论文主体没有显式的长期记忆模块，模型每次动作重规划主要依赖最新观察。笔记中的讨论进一步涉及更长的任务：

  • 世界模型反复生成未来时，预测误差会逐轮累积。
  • 如果模型能够回看较早但更可靠的观察，就可能重新校正场景状态。
  • 这要求记忆不仅保存最近帧，还要记录哪些视觉证据仍然有效、哪些内容已经过时。

笔记还记录了一个分布对齐阶段的设想：让自回归生成的状态分布与教师生成的数据分布对齐。笔记将它写作“DME”，但没有保留完整名称与具体目标函数，这里不进一步解释缩写，也不将其作为 OneWM 的已实现模块。

因此，不能把 OneWM 写成“已经解决了长期记忆和累计误差”。更准确的定位是：

OneWM 先把动作条件的前向预测和动作生成接起来；长期记忆是下一步要补上的能力。

笔记最后还记录了从头训练带记忆的自回归视频—动作模型（native AR）的设想。它对应后续模型设计，没有出现在本文实验中。

10.对我当前研究方向的启发

10.1 记忆不应只按视觉相似度写入

OneWM 的动作条件训练提供了一个很直接的判断标准：

一段历史是否有用，应该看它能否帮助预测后续动作结果，而不只是看它是否看起来新颖。

与前面读过的 JEPA-WAM 相比，两者都关心未来预测监督怎样进入动作策略，但监督内容和连接方式不同。JEPA-WAM 预测联合当前与未来的视觉表征；OneWM 则显式指定动作，让视频预测学习这些动作的视觉后果。加入记忆后，可以进一步检查历史信息到底改善了状态估计、动作选择，还是动作后果预测。

10.2 OneWM 没有解决的研究问题

如果要把它和记忆结合，不能只是在输入前面追加几帧。更具体的问题是：

  1. 历史观察进入视频预测分支、动作分支，还是两者都进入？
  2. 记忆中的历史动作是否作为干净条件，还是只作为视觉上下文？
  3. 记忆写入应该由场景变化、动作后果还是预测误差触发？
  4. 当当前观测与记忆冲突时，模型如何判断哪个更可信？
  5. 训练时依赖示范历史，部署时依赖模型自己生成的动作和记忆，两者之间是否存在分布差异？

一个清楚的四组实验是：

  • 无记忆 + 无动作条件预测；
  • 无记忆 + OneWM 的动作条件预测；
  • 有记忆 + 无动作条件预测；
  • 有记忆 + OneWM 的动作条件预测。

这样才能判断 memory 和 action-conditioned world modeling 是简单叠加，还是确实存在协同。

11.还需要验证什么？

OneWM 的内部对照支持了两类监督的性能互惠，但对内部表征改善的解释还需要更直接的分析。例如，可以在相同初始状态下替换动作，检查预测是否跟着动作改变；也可以逐轮记录想象误差，观察接触、遮挡和物体关系从哪一步开始失真。

对我的研究，更具体的问题是：记忆中保存的可靠历史观察，能否纠正这些状态误差？实验既要比较策略成功率，也要比较多轮预测的状态一致性，并单独计算读取记忆的开销。这样才能确定记忆带来的收益来自哪里。
