World-T³: Test-Time Training as Persistent Memory for Real-Time Video World Models

这篇工作让视频世界模型把离开近期上下文的场景内容写入固定规模的快速权重，再按相机位姿读取。最值得借鉴的是 RLS 对相关观测的累计回归，而非仅仅延长上下文。对 JEPA + VLA + Memory 方向，它提供了抗冗余写入的具体思路，但其证据来自相机控制的视频重访，不能直接外推成机器人任务状态记忆或动作能力。

论文：arXiv:2610.17434v1 · 项目主页。PDF 的 arXiv 页脚标注 2026-10-12，首页另标 Date: October 14, 2026；本文标题按前者记录。内容依据本地原文和阅读笔记整理。

1.What？

World-T³ 是相机控制的自回归视频世界模型。输入初始图像、场景文本和 6-DoF 相机轨迹，模型逐块生成视频，并尽量在返回旧视角时恢复之前出现过的场景。

它使用两种互补的信息来源：有限长度的近期视觉上下文，以及持续更新的参数化记忆。早期内容离开窗口后，其“位姿—视觉内容”关联被写入快速权重；再次收到相近视角时，模型通过位姿查询读取这些关联。

这里的“世界模型”直接输出视频，没有机器人动作专家、任务奖励或闭环操作策略。相机轨迹是控制条件，不能等同于机械臂动作。

2.Why？

局部连贯不等于长期一致。视频模型可能连续生成看起来合理的房间，但当相机转回来时，窗户、家具或局部结构已经变了。它生成了另一个合理场景，却没有保留第一次建立的世界状态。

不断保存历史帧会增加存储和注意力成本；固定容量记忆又要处理压缩与干扰。对连续相机运动，另一个问题尤其明显：相邻位姿高度相关，多次朴素梯度写入会反复强化相同方向，影响已有绑定。

World-T³ 追问的是：如何在历史不断增长时，仍以固定规模的状态读取旧场景，并让相关观测的写入具有明确的累计优化目标？

3.How？

3.1 有界上下文与长期记忆分工

图源：原文 Figure 3。首块作为 sink 保留，其他离开窗口的块进入 TTT 记忆。

将视频分为 latent blocks，生成第 b 块时使用

pθ(xb∣Cb,Mb,T1:b,cI,c),Cb=[s;xb−K:b−1],

其中 s=x1 是持续保留的首个生成块，近期干净块维持局部连续性， Mb 保存已移出窗口的信息。sink 的存在不代表所有早期内容都仍在注意力上下文中。

参考设置每块包含 3 个 latent frames，活跃窗口为 21 个 latent frames，含当前待生成块；满窗口下，干净上下文至多为 18 个 latent frames。它们经过 VAE 的时间压缩，不是同样数量的原始视频帧。单个常规生成块对应 12 帧视频。

3.2 位姿作为 key，干净内容作为 value

相机几何通过 Plücker raymap 编码。对像素射线，若方向为 d 、相机原点为 o ，其六维表示为

r=(d,o×d).

所有位姿相对首帧表达。离开窗口的干净块 ej 被转换为

kj=φK(Πej),vj=φV(hej).

Π 是相机射线图， h 是该块的干净隐藏状态。key 来自位姿，value 来自内容，因此写入机制与目标块的扩散噪声解耦。

每个 DiT 层都有两层 MLP 形式的记忆：

ϕ(k)=gelu(W1k),m=W2ϕ(k).

部署时 W1 固定，动态变化的是读出矩阵 W2 及逆相关状态 P 。固定的非线性特征映射，是下面 RLS 精确求解成立的重要条件。

3.3 RLS 不是对最近一帧单独做一次梯度下降

累计第 j 次写入后，论文希望求解加权 ridge regression：

minW2∑i≤jwi∥vi−W2ϕi∥22+λ∥W2−W2(0)∥F2,

其中 wi 为学习得到的标量权重， W2(0) 为学习到的读出先验。维护

Pj=(∑i≤jwiϕiϕi⊤+λI)−1.

对新关联 (ϕ,v,w) ，从更新前的 W2,P 出发：

g=Pϕw−1+ϕ⊤Pϕ, W2←W2+(v−W2ϕ)g⊤,P←P−gϕ⊤P.

右侧均按更新前状态计算。原文取 λ=10−3 、 P0=I/λ 。

残差 v−W2ϕ 描述当前关联尚未被解释的部分； Pϕ 根据历史 key 的相关性调整更新方向，使已被充分覆盖的方向受到抑制。它同时考虑“当前预测错多少”和“这个方向过去见过多少”，比只看单次重建误差更明确地处理相关观测。

在特征、权重及 K/V 关联固定时，递推给出累计目标的精确最优解，数学上对这些关联的呈现顺序不变。这不表示完整视频系统与时间顺序无关。 改变生成顺序会改变内容、隐藏状态及后续观测；它也没有证明 RLS 自动理解事件先后。

RLS 每次淘汰块时按层更新，不是检测到冗余就完全跳过写入。对历史长度保持常数成本，也不代表对记忆特征维度没有成本，逆相关矩阵本身需要存储和计算。

3.4 读取与外层学习

生成目标块时，使用其相机 raymap 查询当前记忆：

mb=W2gelu(W1kb),hb←hb+γ⊙Woutmb.

检索结果通过学习到的通道门控残差注入 DiT。在线状态在同一目标块的去噪过程中保持不变，因此优化后的实现每块只算一次记忆读出，再复用到 4 次去噪。

训练时，视频去噪目标通过递推更新训练记忆投影、读出先验、样本权重和门控；部署时这些慢参数固定，仅更新 W2,P ，不通过整个 DiT 做在线反向传播。附录同时说明，干净上下文 K/V 会缓存并从计算图分离，不能把训练实现理解为跨全部历史保存完整梯度图。

3.5 三阶段、五次训练

阶段 实际训练环节 作用
Stage 1 双向相机条件 SFT 让预训练视频模型跟随相机轨迹
Stage 2 block-causal 适配，再进行记忆增强训练 支持连续生成及超窗口重访
Stage 3 Consistency Distillation，再进行双教师 DMD 压缩到 4 步采样并保留质量与记忆

Stage 1 使用 LoRA 和新相机模块，基础骨干其他权重冻结；Stage 2 后半段合并 LoRA 后联合训练完整 DiT、相机模块与 TTT 记忆。

双教师 DMD 分工如下：双向教师约束局部视觉质量和运动连贯性，带记忆的自回归教师约束长程场景一致性；每个教师配有从学生样本学习的 critic。记忆教师与其 critic 都按学生自身 rollout 构建记忆状态，使监督面对学生生成过程中实际遇到的历史。

参考训练并非始终同时启用两个分支：DMD 前 399 次迭代只有双向监督，第 400 次起加入记忆教师；共 800 次 critic 更新，generator 每 5 次更新一次。少步生成是训练和系统优化共同实现的，不能全部归功于记忆模块。

4.实验结果

4.1 怎样确认测到了超窗口记忆？

评估包含 120 段未见视频，各为 160 帧、16 FPS、1280 × 704，相机在第 80 帧处反向。固定比较四组零起始帧对： (8,152) 、 (16,144) 、 (24,136) 、 (32,128) 。

对应间隔为 36、32、28、24 个 latent frames，全部大于 21 帧活跃窗口。因此测试要求在离开近期上下文后恢复旧内容，而非只复制邻近帧。

指标需要分清参照对象：

指标 比较什么 解释边界
Semantic Similarity 生成视频中去程与回程的 DINOv2 特征，取 1 减平均余弦距离 衡量自身重访一致性，单独使用无法排除一致地生成错误内容
Revisit PSNR 生成回程帧与对应的 VAE 解码 GT 同时受到外观误差与相机偏移影响
RotErr 等位姿指标 从生成视频估计的轨迹与规定轨迹 另受位姿估计器噪声影响
VBench 七维平均 图像质量、审美和局部时序等 不等于长期场景记忆质量

原文不对回程帧做事后视角对齐，因此 PSNR 包含轨迹跟随的影响，不能将全部改善都分配给记忆存储。

四步学生相对 SANA-WM 的重访 PSNR 提升 4.79 dB；DINOv2 距离从 0.0800 降到 0.0390。120 条 clip 中，分别有 112 条 PSNR 更高、111 条 DINOv2 距离更低，原文使用 clip 级配对双侧 sign test 支持这两个差异。

学生相对教师的 PSNR 从 16.69 增至 18.31 dB，但 VBench 从 75.15 降至 74.52，Local Memory 从 0.9442 降至 0.9258。这里的 Local Memory 是相邻帧切换和突变构成的平滑性指标，不是 TTT 状态容量。结果支持更好的长期重访与更快生成，没有支持所有视觉维度全面提升。

另一个限制是消融归因：原文给出了完整系统、教师学生及相机 sweep 分组比较，但未给出同一训练预算下“无记忆／朴素梯度写入／RLS”的独立受控结果。系统效果明确，RLS 对最终分数的单独贡献仍需要进一步实验。

4.3 实时生成的条件

以下效率来自原文 Appendix E 的 30 秒级工作负载，在同一类 NVIDIA B200 上测量，并非直接用 10 秒重访集的帧数除以耗时：

方法 采样设置 单卡吞吐 / FPS 峰值显存 / GB
SANA-WM 4 步生成 + 3 步 refinement 14.2 48
World-T³ Stage 3 4 步 20.6 54

视频播放帧率为 16 FPS，所以 20.6 FPS 在该配置下超过实时。它不是机械臂控制频率，也不是普通消费级 GPU 上的实测速度。SANA-WM 的峰值显存来自 PyTorch allocator，其他相关测量使用设备级统计，口径也并非完全一致。

World-T³ 的单卡实现优化使同一四步学生的 465 帧 rollout 从 70.48 秒降至 22.59 秒，约 3.12 倍，包括编译、VAE 解码、注意力 kernel、RoPE 及特征复用等。教师 50 步到学生 4 步是 12.5 倍的步数减少，不能直接当作实测总耗时加速。

部署成本在窗口填满后不随 rollout 长度增长，但上下文仍需重新编码：滑窗改变了多数保留块可见的前驱，不能把全部旧 KV 永久沿用。优化只能复用未变化的前缀及 sink 等有效部分。

4.4 数据与复现预算

训练使用约 908K 相机标注片段，其中 307K 为带重访的片段。真实视频通过 VGGT-Ω 估计相机参数，重访增强限定在静态场景，排除跨访问变化的动态实体。

五次训练分别使用 512、256、128、128、128 张 GPU。基础模型为 Wan2.2-TI2V-5B，DiT 有 30 层、宽度 3,072。对于当前研究，完整复制这条训练流水线成本很高，更合理的是先隔离记忆机制，在既有策略和明确的历史依赖任务上验证。

5.Takeaways:

5.1 与 T²Mem、JEPA 和价值记忆怎样联系？

工作 记忆或监督对象 主要学习信号 已有证据
T²Mem 观测语义到历史内容的参数化关联 内层自监督写入，外层专家动作 RoboMME 操作与记忆干预
World-T³ 相机位姿到场景内容的参数化关联 内层 RLS，外层视频生成 超窗口视角重访
JEPA-WAM 当前与未来的视觉潜在表征关系 潜空间预测与动作学习 原文策略评估
Value as Memory 近期任务进度相关 value 价值学习、后训练与策略条件化 在线操作及 value 替换

笔记中“把预测未来与保存过去结合起来”的思路值得继续，但两者需要不同的验证：未来预测要检查是否保留动作相关变化，历史记忆要检查关键证据消失后是否仍可读取。预测得准不自动意味着记得对，记得对也不自动意味着能执行对。

World-T³ 的 key 设计适合静态空间的视角重访。机器人操作中，相同位姿会看到不同物体状态，同一物体也会出现在不同位置；仅用相机 key 会把这些情况混在一起。相应地，RLS 的累积最小二乘更适合协调固定关联，而动态世界可能要求覆盖、遗忘或条件化地保存冲突绑定。

5.2 对后续实验更直接的启发

以下属于研究设计，尚未由原文验证：

  1. 在同一 VLA 上固定视觉特征与数据，对比普通梯度写入、T²Mem 式幅度调节和 RLS，分别测量关键历史的保持、策略成功率和计算成本。
  2. 区分检索 key 的作用：位姿、对象身份、对象状态和动作上下文分别提供什么信息；用同位姿不同状态、同对象不同视角检验绑定是否混淆。
  3. 加入 JEPA 潜空间预测监督时，对照动作损失、预测损失及联合目标，验证所谓新信息是否真正改变后续决策，而非仅是相机移动或背景变化。
  4. 沿用 T²Mem 的冲突记忆替换和证据窗口实验，再加入物体被移动、交换和任务阶段回退，检查旧记忆何时应该被保留、修正或遗忘。

5.3 局限性 & 未来工作

位姿噪声会让 query 与记忆无法对齐；固定容量不代表无限存储，超训练时长的生成仍会积累纹理和细节退化。原文的静态场景重访也没有直接证明遮挡对象身份、任务进度或事件顺序记忆。

我更关心的下一步是：让参数化记忆维护与动作相关、会随事件变化的世界状态，并明确处理“过去看到的内容现在已过时”。RLS 给出了抗相关冗余的工具，但是否写、如何读、何时修正，仍需任务监督和受控干预来回答。
