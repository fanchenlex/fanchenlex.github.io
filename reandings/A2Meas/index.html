Toward the Era of Agentic Embodied Intelligence

A²-MEAS 用视觉历史和未来特征预测增强动作策略，再通过一个可训练的纠错接口，把高层模型的建议、空间证据与执行历史送入动作生成。它关心的不只是失败后重新尝试，还包括这次应该怎样改变动作，以及恢复后能否继续完成原任务。部署时所有模型参数保持固定。

工作类型(首次/改进)技术路线创新点日期
改进Qwen3-VL + 潜在世界模型 + flow-matching 动作专家 + 多 agent 纠错将有空间与历史依据的纠错信息编码为连续 code，在动作隐藏层中调整轨迹2026-11-06

1.What？

这篇文章有两层设计，读的时候需要分开：

层次 输入和职责 对应能力
A²-WLA 动作模型 读取完整任务指令、近期视觉历史和机器人状态，并预测未来视觉特征 生成连续动作，估计局部阶段进度
A²-MEAS 协作系统 在动作模型之外加入 MetaBrain、诊断 agents、执行记录和纠错接口 检查进展、诊断异常、调整动作并验证恢复

A²-WLA 本身就能闭环控制：生成一个动作块，执行前缀，再读新观测重规划。A²-MEAS 在这个基础上处理需要额外诊断的失败。基础策略的成功率、完整系统的成功率、局部失败后的恢复率，是三种不同结果。

论文所说的 code as a scaling interface，指一个连续的学习表征。高层建议先被编码，再通过 Adapter 改变动作专家的隐藏状态；这里没有让高层模型编写并执行控制程序。

2.Why？

长任务中，一个局部动作完成后，未必留下适合下一步的状态。比如，抓住瓶子解决了“有没有拿到”的问题，但抓取位置和朝向仍可能妨碍倒水；滤器被重新提起，也不代表接下来能稳定放到杯口。

失败后如果只重复原来的指令，策略可能继续生成相似动作。纠错需要把几个信息连起来：

  • 刚才实际执行了什么，异常从什么时候开始；
  • 现在物体、接触和支撑关系变成了什么；
  • 下一次应改变接近方向、目标位置还是夹爪时机；
  • 修正之后，原任务还有哪些条件没有满足。

因此，论文把高层推理与底层动作之间的接口作为研究重点。MetaBrain 负责提出有依据的改变，动作模型负责将这些信息转成连续控制。两者共享实际执行记录，而不是只交换一句新的子任务指令。[§1–2]

3.How？

3.1 三组 agents 如何协作？

组成 具体工作
MetaBrain 保持完整任务目标，检查进展，回看失败区间，提出纠错指令
诊断 agents 定位物体、核对空间关系、追踪运动变化，结合可用状态信号判断接触、支撑和可执行性
A²-WLA 解释观察并生成动作；恢复时接收纠错 code，通过 Adapter 修改动作生成

诊断部分按问题调用工具。原文列举了 DINO 特征、SAM 分割、追踪、可用深度或三维估计、机器人状态和运动学检查，没有规定每次都调用一套固定的感知模型。

例如，“物体在夹爪之间”不足以证明抓稳了。还要看它是否随手一起运动，以及夹爪状态是否支持这个判断。证据不足时，系统把结果保留为未知，并在预算内请求新观测；它与已经确认失败的情况对应不同处理。

共享执行记录 Rt 把执行前后观察、实际控制量、已执行长度和时间戳关联起来。尚未执行的动作提案单独保存，不能把模型想做的动作当成已经发生的历史。[§1.1–1.2、§2.2]

3.2 A²-WLA：历史、预测与动作生成

基础模型由三部分构成：

模块 实现 输出
视觉语言主干 2B Qwen3-VL，读取任务指令与多视角历史 当前上下文 C ，以及预测的潜在动作 z^
潜在世界模型 从当前多视角特征与 z^ 预测未来特征，再做空间压缩 未来上下文 C+
动作专家 约 300M 参数、18 层 Gemma 风格 Transformer 连续动作块与局部阶段进度

动作专家每层都有动作 token 自注意力，交叉注意力则交替读取两种上下文：按从 0 开始的层号，偶数层读 C ，奇数层读 C+ 。本体状态也投影后送入动作专家。

BEHAVIOR 参考配置预测 50 步、23 维动作，用 10 步 flow integration 生成，最多执行前 32 步，随后获取新观测。未执行的后缀由下次预测替换。这里 32 步在 30 Hz 下对应约 1.07 秒的控制时长，实际调用间隔还包含推理和通信时间。

它使用 VLM 加动作专家的结构，但不能直接称为官方 π0.5 模型。论文单独报告了初始化、网络设计和训练配方。[§3、§4.2]

3.3 六帧历史怎样编码？

每个相机输入 5 张过去图像加当前图像。时序 patch kernel 为 2，六帧形成三个配对表示，先经过参数共享的前四个视觉块，再用 4×4 池化与学习查询压缩。

设第 k 对图像的压缩表示为 fk ，原文式（5）计算相邻差分：

dk=LN(W(fk+1−fk)+PE(k)),k∈{0,1}.

差分特征作为后续门控交叉注意力的 key、value，经残差融合、剩余视觉块和 token merger，形成送入语言主干的视觉 token。

这个设计让视觉表示包含“最近怎样变化”，但差分不是经过时间标定的物理速度。训练还会改变采样间隔：五个回看距离分别从由 [30,84,138,192,246,300] 划分的五个区间中按 log-uniform 采样，再加当前帧，并在相机间对齐时间戳。

部署的固定相对偏移为：

以 30 Hz 计算，最早一帧距当前约 8.53 秒。超出 episode 起点时重复初始帧，并携带时序 padding 标记。

这是一段每次调用重新编码的滑动窗口，没有跨调用递归积累的隐藏状态。 用于诊断的较长执行记录 Rt 与六帧视觉输入是两条路径，不能把二者统称为同一个 memory bank。[§3.1、§3.4.1]

3.4 世界模型预测什么，未来监督从哪里来？

世界模型包含冻结视觉编码器、逆动力学编码器和未来特征预测器。设 F 为当前多视角 patch 特征， F+ 为 50 个控制步之后的真实特征。预训练阶段：

z∗=Einv(F,F+),F^v+=Dv(F,z∗).

逆模型用当前与未来观察，提取解释多视角变化的共享潜在动作 z∗ 。每个视角的预测器都读取当前多视角特征和这一共享变量，重建自己的未来特征。训练使用跨有效视角加权的 Smooth L1 重建损失，并加入潜变量正则。[式（6）、（8）]

预训练后冻结逆编码器，让视觉语言主干在只看当前、过去观察和指令的条件下预测 z^ ：

LLA=∥z^−sg(z∗)∥22.

推理时没有真实未来，因此改为：

F^v+=Dv(F,z^),C+=P(F^+).

其中 P 压缩未来特征，保留相机身份，并用有效视角 mask 排除缺失输入。动作专家读取这些预测特征，而不是未来真值。

这里有三个容易混淆的地方：

  • z∗ 是从视觉转移学习的潜在表示，不是真实关节动作序列的直接编码。
  • 推理移除需要真实未来的逆模型，但仍保留未来特征预测器，预测结果实际参与动作生成。
  • 监督包含潜动作预测和未来特征重建，不能直接等同于 V-JEPA，也不能套用“预测分支只在训练时使用”的说法。[§3.2、§3.4.2]

3.5 高层纠错怎样进入动作？

在当前恢复状态，先关闭纠错分支，由基础策略生成一段尚未执行的动作提案 A^tbase 。纠错编码器将它与其他三类信息融合：

ct=Eϕ(ut,Gt,Rt,A^tbase).
输入 作用
ut 纠错语言及方向参考，例如相对于杯口重新对齐
Gt 核验后的物体区域、交互点与空间关系，并保留相机、帧和坐标依据
Rt 实际执行动作及对应观察，说明此前尝试了什么
A^tbase 说明当前基础策略在不干预时会怎样行动

完整任务指令仍经策略原有语言路径输入，当前视觉和预测未来上下文也保留原路径。 ct 是额外的纠错条件，不替换这些输入。[§2.3、式（2）]

动作专家第 9 层后，Adapter 修改隐藏状态：

hτ′=hτ+α⊙Cϕ(hτ,ct).

hτ 包含动作块各位置的隐藏表示； α 是按通道学习、在动作位置间广播的缩放。后面 9 层将修改后的表示转成 flow velocity。[§2.4、式（3）]

注意区分物理时刻 t 和 flow 内部时间 τ ：一次动作块生成期间，code 固定；每个 flow integration 步的隐藏状态与 Adapter 残差重新计算。 残差读取各动作位置的隐藏表示，因此可以前面抬起、后面重新接近，并非给整个动作块的所有关节加同一个偏移。

完整纠错分支少于 100M 参数，Adapter 瓶颈宽度为 256。输出投影零初始化， α 初始化为 0.1，所以起始残差为零，初始输出与基础模型一致。

3.6 纠错监督不是在线失败轨迹

论文主要从已有示范离线构建纠错数据：

  1. 在示范状态上运行冻结基础策略，只提供截至当前时刻的观察。
  2. 将未执行的动作提案与专家后续动作对齐时间、坐标和单位。
  3. 在 32 步比较窗口中筛选关键操作阶段的较大偏差，排除越过技能边界或示范终点的位置。
  4. 用图像、空间证据与动作偏差方向组织纠错说明，由 MetaBrain 生成语言标注。
  5. 以专家后续动作作为 flow-matching 目标，冻结基础策略，只训练纠错编码器与 Adapter。

保留的纠错监督最多占约 1,950 小时语料的 2%，即 39 小时。标注可以利用专家动作和未来画面，但这些信息不进入基础策略提案的生成；历史字段仅保留当前时刻之前的示范前缀。

模型在这里学的是如何把提案改向专家续接，不是在真实失败改变后的场景中学习恢复。 部署时，物体可能已经滑落、接触已经改变，状态未必仍在示范分布里。这是作者明确承认的差距。[§2.5、Figure 5]

3.7 从检测异常到恢复任务

正常执行时关闭纠错分支；发现异常后，暂停待执行动作，保存记录，完成必要的停止或姿态准备，再重新观察。恢复状态必须同时用于基础动作提案、空间证据和纠正动作生成。

执行前核对证据是否仍然有效，以及可用的关节限位、障碍间隙检查。执行修正前缀后，再观察所需物理条件是否恢复：成功则返回未完成的原任务，失败则带着新记录继续诊断。

参考配置每次异常最多增加两个视角，每个视角限时 5 秒；最多三次物理重试；MetaBrain 单次请求 10 秒超时，整次恢复事件限时 60 秒。重新发起查询不重置预算。这个机制包含暂停与诊断，论文没有把它验证为适合快速异常的即时反应控制器。[§2.6]

4.训练：哪些阶段更新哪些参数？

阶段 训练内容 参数处理
世界模型预训练 多视角转移潜变量、未来特征重建 冻结视觉编码器，训练逆模型和未来预测器
VLM 预训练 潜动作、FAST token、连续动作查询及误差评分、具身问答 训练 VLM 和相应预测头，不运行连续动作专家
连续动作联合训练 flow matching、未来特征一致性和辅助监督 联合训练 VLM、未来预测器、动作专家及启用的辅助头；关闭 FAST token 损失
纠错训练 纠错上下文到专家续接动作 冻结基础策略，只更新纠错分支

连续动作的噪声路径与监督为：

Aτ=(1−τ)A+τϵ,ϵ∼N(0,I), LFM=E[MSEM(vθ(Aτ,τ∣s,C,C+),ϵ−A)].

M 排除无效时刻和 padding 控制维度；推理从 τ=1 向 τ=0 积分。辅助项还包括未来特征、动作块表示对齐、末端几何、任务身份与局部阶段进度。[§3.4]

4.1 进度值不等于完成概率

在锚点 t 所属的技能区间 [t0,t1) ，第 j 个动作的进度目标为：

pt,j=clip(t+j−t0+1t1−t0,0,1).

只有仍处于该技能区间的位置参与进度损失。它监督的是示范区间中经过了多少相对时间，因此接近 1 不代表已经抓牢、插入或放稳。进度预测还覆盖动作块未执行的后缀，运行时必须结合实际前缀与新观测判断完成。[式（18）、§3.4.3]

4.2 Knowledge insulation 只缩小一条路径的梯度

当前上下文送往动作专家时使用：

KI(h)=γh+(1−γ)sg(h),γ=0.1.

前向值不变，经过这条路径的梯度缩小为原来的 0.1。未来预测和其他辅助监督仍有自己的梯度路径，所以不能理解为冻结整个 VLM。[式（20）、§3.4.4]

4.3 训练预算与可借鉴的实现

前三个基础阶段均使用 64 张 GPU；VLM 阶段训练 150k 步，连续动作阶段训练 500k 步。纠错分支使用 8 张 GPU、全局 batch 256、6k 步。完整方案的复现成本需要按这些配置估计。

工程上值得借鉴的是：同一示范的视觉历史、指令和状态只编码一次，多个噪声—时间样本共享该 prefix。每条示范先计算两个 flow 样本，难样本分配更多，最多八个、批次目标平均四个。损失先在每条示范内部平均，再在示范间平均，避免额外计算次数直接变成更大的显式样本权重。

论文最终报告 8 张 GPU 上 427.1 条示范/秒，相对同 GPU 硬件的 π0.5 参考实现约为 4.03 倍。两者 batch 按资源使用选择，这衡量特定实现吞吐，不能直接换算为相同模型效果下的训练成本降幅。[§4.1]

5.实验：基础动作能力与协作收益

5.1 BEHAVIOR 2026：多模型带来了相当一部分增益

公开集包含 100 个任务，每个配置记录 1,000 次评测。Q-score 统计满足目标条件的比例，完整成功率要求该次任务全部完成。[Table 5]

配置 Q-score 完整任务成功率 至少成功一次的任务数
单个 A²-WLA 0.4597 27.20% 70/100
多模型 A²-WLA 0.6040 40.60% 80/100
完整 A²-MEAS 0.6411 45.40% 88/100

单模型到多模型同时包含任务专门化、检查点选择和执行配置的收益。每个 episode 使用预先确定的一套任务对应策略，并不是执行中随意切换模型。完整系统在多模型基础上再增加 4.80 个百分点的成功率，不能把单模型到最终系统的全部提升归给 Adapter。

公开系统使用远程 Qwen3.8-27B MetaBrain。官方隐藏集受自包含部署和 24 GB 显存限制，换成 Qwen3.5-2B coordinator：[§5.2.3]

隐藏集提交 Q-score 完整任务成功率
A²-WLA 0.4951 30.95%
A²-MEAS 0.4975 32.05%

公开集和隐藏集的评测样本及部署配置不同，分数差距不能全部归因于 coordinator 大小。摘要中“较 2025 冠军提高约 2.21 倍”也跨越 benchmark 年份和训练配置，应保留比较条件。

5.4 咖啡失败恢复：使用的是另一种 Adapter

咖啡实验针对两个容易抓取失败的步骤：从架子取滤器并放稳在杯口，以及从杯口取走滤器。失败后回退，再比较基础策略重试与历史条件 Adapter；每个步骤、每种条件 100 次。[§5.4.2]

失败后重新执行 取滤器并放到杯口 取走滤器并转移
基础策略重试 14/100 8/100
历史条件 Adapter 94/100 82/100

这里成功要求完成放置或转移、释放滤器并撤回夹爪，相应步骤还检查稳定支撑或咖啡渣处理，不只是重新夹住物体。

这组数字对应约 86 万参数的轻量实现：读取当前观察和最多 64 个历史状态转移，通过交叉注意力读取历史，在动作输出头前加入门控残差。它以纠正片段的实测状态序列监督，基础策略冻结，门控零初始化。

它与 Figure 3 中四输入 code、少于 100M 参数、动作专家第 9 层后注入的完整接口不同。真机结果支持历史条件纠错的效果，不能据此认定完整四输入接口已在这组真机实验中得到验证。

6.消融：什么信息真的起了作用？

6.1 基础策略：表征、初始化和数据共同影响结果

Selected12 的基础策略消融关闭高层纠错，每个配置汇报三轮、每轮 120 次评测的均值。[Table 11]

累积配置 Q-score 完整成功率
动作策略预训练初始化 0.4846 39.72%
＋未来世界特征 0.5183 42.50%
＋运动感知历史编码 0.5279 45.56%
＋技能边界采样与平衡 0.5546 46.67%
＋额外成功 rollout 0.5905 50.28%

最后一行额外引入了 2,400 条成功轨迹，包含初始位置扰动与成功筛选，增益不能全部归给结构。原文“当前帧 8.33% 对比六帧 13.33%”是在六帧训练模型上删去推理历史的比较，也包含输入分布改变，不能作为两套独立训练方案的严格对照。

6.2 冻结基础策略后，纠错需要哪些条件？

另一组 12 任务纠错子集，每配置 120 次评测，固定相同 A²-WLA 权重，只改变纠错条件。[Table 12]

条件变化 Q-score 完整成功率
不使用 Adapter 0.5310 41.67%
同时去掉纠错语言、任务文字和结构化空间依据 0.5344 43.33%
历史只留最新一条状态—动作记录 0.5356 44.17%
去掉基础动作提案编码 0.5542 47.50%
去掉结构化空间依据 0.5570 49.17%
完整 Adapter 0.6108 52.50%

较长历史、空间依据和当前提案都提供了有用信息。“去掉语言和 grounding”一行同时删除多项输入，不能独立归因于纠错语言。在同任务另一组不重叠实例上，完整 Adapter 的成功率为 58.33%，无 Adapter 为 50.83%，支持其收益延伸到这些任务的新实例。[§6.3.3]

6.3 局部恢复与最终完成要分别看

原文把物理恢复、限时有效继续和剩余预算内最终完成分开统计：[Table 13]

纠错接口 物理恢复率 有效继续率 最终任务完成率
重述指令 46.27% 25.37% 38.81%
VLM＋IK 几何纠正 52.05% 28.77% 45.21%
隐藏空间 Adapter 54.93% 33.80% 43.66%

后三项都只统计触发过纠错的 episode，每个 episode 从首次触发计一次；不同接口触发的 episode 群体可以不同，参数量和计算量也没有匹配。这不是相同失败状态上的配对比较。

Adapter 局部恢复略高，最终完成率却没有超过 VLM＋IK。有效继续率有固定时间窗，最终完成使用剩余 episode 预算，所以后者也不必低于前者。看这组结果时，不能把“纠正动作成功”直接替换成“原任务完成”。

6.4 增加子任务提示不一定改善长任务

Selected12 上，完整任务指令配置得到 45.83% 成功率，加入异步 VLM 选择的 Current focus: 配置为 30.83%。这比较两套整体训练与执行配置，不能直接推出所有子任务分解都无效。

在固定同一个 Focus 策略的调度对照里，在线 VLM Focus 为 30.83%，仅完整目标为 30.00%，只相差 120 次评测中的一次成功。论文还比较模拟器辅助的固定顺序与可重排调度，二者的 Q-score 与成功率没有同时改善。[§6.4]

对我更有用的是后面的原因分析：上一步完成后，物体朝向、接触和持有状态是否满足下一步，并不能从子任务名称判断。历史应帮助识别这些物理前提，而不只是保存“已经执行到第几个技能”。

7.与 Memory＋JEPA 研究的关系

7.1 哪些信息算历史，哪些已经成为记忆？

路径 本文的做法 对后续研究的问题
普通动作输入 固定六帧滑动窗口，每次重新编码 同预算下，持续更新的记忆是否比重新读取窗口更有效？
诊断历史 外部记录实际动作及前后观察，供失败回看 如何选择仍有效的证据，避免过时状态误导纠错？
世界预测 用视觉转移学习潜动作，预测未来特征，并在推理保留预测器 动作条件的 JEPA 监督能否训练证据保留，同时减少部署预测开销？
纠错 code 每个修正动作块前由最新上下文重新计算，块内固定 是否需要跨动作块维护可修订状态，而不只编码一次恢复上下文？

这些是我基于本文提出的研究问题。A²-MEAS 没有给出一个跨观察递归更新、固定容量的证据记忆，也没有提供这类记忆满容量后的替换机制，不能替作者补成 FIFO 或检索库设计。

7.2 预测监督应检验延迟后果

这篇工作展示了近期变化与预测未来特征的互补收益，但动作成功不等于记住了离开视野的信息。对于我的方向，应进一步检查：某次交互留下的证据，在若干步之后是否仍支持正确动作与状态判断。

可以将同预算六帧窗口与固定容量持续记忆分别配上有、无 JEPA 监督，形成四组对照，再增加以下评测：

  • 遮挡后或回到旧位置时，是否仍能判断物体、容器与操作状态；
  • 延迟出现失败后，是否能利用较早的观察定位问题；
  • 物理恢复、有效继续、最终完成能否同时改善；
  • 记忆更新、读取与未来预测分别带来多少部署开销。

如果采用真实动作段条件的预测目标，还需要单独说明它与本文视觉潜动作的区别；如果部署移除预测器，也要重新验证策略收益是否保留。本文实验不能直接回答这两点。

7.3 参数中的纠错能力与部署输入中的新信息

纠错训练将语言和专家续接的联系写入编码器与 Adapter 参数；部署遇到的新证据则通过输入和 code 改变行为，参数本身不更新。这两种机制应分开讨论，不能把部署纠错描述成在线微调或参数化记忆更新。

我更想继续研究的是：过去证据怎样影响后续操作的可执行性，以及新的观察与旧记忆冲突时怎样修订。A²-MEAS 的执行记录与恢复评测提供了可借鉴的切入点；要证明一个记忆模块有效，还需要把基础动作能力、历史预算和高层推理能力分别控制住。
