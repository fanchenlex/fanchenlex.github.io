H-JEPA: End-to-End Learning of Hierarchical World Models for Visual Planning

这篇工作研究如何让不同时间尺度拥有各自的世界表征，并通过自上而下的子目标规划解决长时程任务。它对分层记忆设计最有价值的地方，是区分“时间分解”和“表征抽象”，并展示预测学习如何退化为只记住背景的 slow-feature collapse。不过原文不是记忆型 VLA：所有实验的上层状态窗口均为 1，长时程规划收益也不能直接视为跨时刻记忆收益。

1.What？

H-JEPA 从包含观测与动作的轨迹中，端到端训练多层潜空间世界模型。底层面对细粒度状态变化，上层在更大的时间间隔上预测抽象状态。每层都有自己的状态编码器、动作编码器和预测器，并在自己的表征空间里训练、规划。

它把长时程控制拆成两个问题：上层选择通向最终目标的粗粒度路径，下层把上层预测出的状态作为子目标，逐级落实成原始动作。给定的是当前观测和目标观测，原文并未直接构建语言指令驱动的 VLA。

理解本文需要分清三件事：

概念 在本文中的含义 能否直接等同于记忆
时间层级 不同层以不同 stride 预测 不能，预测间隔不等于历史保存长度
表征层级 不同层学习不同的状态空间 不能，需要检验究竟保留什么信息
规划层级 上层给子目标，下层优化动作 不能，它分解的是未来规划问题

2.Why？

单层世界模型需要同时表示高频动作细节和低频目标结构。例如 AntMaze 中，腿部摆动决定局部运动，但长程导航主要依赖身体位置与迷宫布局。若同一个潜空间距离同时承载两种信息，到目标的距离可能被局部姿态扰动，长时程动作优化也更困难。

一种办法只是减少预测频率，但始终使用同一个表征空间。H-JEPA 进一步让每层学习自己的状态编码：高层是否会在更长预测间隔下，自发舍弃对该尺度无帮助的细节？这种抽象是否还能让规划代价更容易优化？

只有将时间分解与表征变换分别消融，才能知道层级结构的收益来自哪里。

3.How？

3.1 stride 与 window 是两个独立参数

示例中 w2=1,s2=2 ，上层状态逐点编码，动作则汇聚两步。

底层将图像编码为 zt(1)=E(1)(ot) ，并把原始动作块编码为 at(1) 。上层用两个参数定义时间关系： sℓ 控制相邻上层状态相隔多少下层步， wℓ 控制一个上层状态覆盖多少下层状态。

以半开区间表示切片：

zt(ℓ)=E(ℓ)(ztsℓ:tsℓ+wℓ(ℓ−1)), at(ℓ)=A(ℓ)(atsℓ+wℓ−1:(t+1)sℓ+wℓ−1(ℓ−1)).

动作编码覆盖从当前上层状态到下一上层状态的完整转移，汇聚长度是 sℓ ，不由 wℓ 决定。

原文所有实验都使用 wℓ=1 。 因而上层状态编码器并没有把一个长历史窗口压成记忆；它对下层状态逐点变换，再以更大的 stride 预测。主要仿真实验使用 stride 2。可以借鉴其分层思想，但不能据此声称原文已验证“分层历史记忆”。

3.2 每层的预测损失与表征正则

每层在 teacher forcing 下，以之前的潜状态和动作预测下一潜状态。省略 batch 与上下文索引，可将其目标写成：

L(ℓ)=Lpred(ℓ)+λℓSIGReg(Z(ℓ)),

其中预测项为潜状态的均方误差，SIGReg 约束 minibatch 中表征的分布，避免所有状态变成同一个向量。上层损失会穿过上层编码器，继续更新下层表征，整个层级端到端训练。

底层基于 LeWM：ViT-Tiny 使用全局 CLS 表征，搭配 causal Transformer predictor；上层使用两层 MLP 状态编码器与 causal Transformer predictor。这与 JEPA-WAM 使用冻结 V-JEPA 教师提供稠密 patch 目标的训练方式不同，不能把两者的 encoder、目标及梯度路径直接混用。

3.3 自上而下规划

下层预测先映射到上层空间，再与上层子目标比较。

当前图像与目标图像先逐层编码，得到每层初始状态与目标 g(ℓ) 。最高层通过梯度下降优化宏动作，使 rollout 的末端接近目标：

mina0:HL−1(L)‖z^HL(L)−g(L)‖22.

最高层优化出的预测状态成为下一层的子目标。下层执行更密集的 rollout，并将预测经 E(ℓ+1) 映射到上层空间后匹配子目标。比较发生在同一个 latent space，而不是直接拿不同层的向量求距离。

闭环控制只匹配下一子目标，执行一段底层动作、获得新观测，再重规划；开环设置可匹配多个子目标。它不是先生成一段语言计划，也不是直接回归专家动作的 action head，而是显式优化世界模型中的动作序列。

3.4 为什么非塌缩表征仍会丢掉控制信息？

DROID 上出现了一个很重要的失败：场景、光照、物体在 episode 之间变化很大，编码器可以只保留“这是哪个场景”，在 episode 内几乎不再表示机械臂运动。背景非常容易预测，表征跨 episode 仍有方差，SIGReg 并不会必然把这种解排除。

这就是 slow-feature collapse：表征在统计上没有完全塌缩，但与动作相关的信息已经丢失。

作者加入 inverse dynamics loss，用相邻状态预测其间动作：

Lidm(ℓ)=E‖I(ℓ)(zt(ℓ),zt+1(ℓ))−sg(at(ℓ))‖22.

上层预测的目标是对应尺度的宏动作，采用 stop-gradient，防止编码动作本身随意变化来降低损失。该约束要求状态对包含动作相关的变化，而不只是可预测的静态背景。

对于后续记忆设计，这是一个直接警示：更新缓慢、预测稳定、表征方差正常，都不能单独证明记忆保存了控制所需的信息。

4.实验结果

4.1 层级规划的收益与适用条件

原文在 FourRoomDistractors、Visual AntMaze、Push-T 和 OGBench Cube 上评估。AntMaze 的 flat LeWM 为 18.0±3.5% ，三层 H-JEPA 为 73.3±3.5% ，并能在较低规划计算量下达到更高成功率。这里的误差是跨种子的标准误 SE。

作者还设置 HWM 对照：上层状态编码器改成恒等映射，其他实现、训练数据及深度设置一致，各层共享同一状态空间。HWM 在四个环境都体现出时间分解的价值；学习独立表征空间带来的额外收益在 AntMaze 最明显，在 Cube 部分设置中也存在，而 FourRoom 与 Push-T 中两者较接近。

因此，原文支持的是“时间分解普遍有帮助，独立表征在部分环境进一步有帮助”，而不是“任何任务都必须使用多层潜空间”。

4.2 更好的距离函数不能替代完整规划分解

原文 Table 1 固定三层模型内的 level-1 dynamics 和 planner 设置，只切换评价 rollout 的代价空间：

三层模型中的规划设置 AntMaze 成功率 / %，mean ± SE
使用原生 level-1 cost 16.7 ± 1.8
映射到 level-2 后计算 cost 20.7 ± 4.8
映射到 level-3 后计算 cost 22.0 ± 2.3
完整层级规划，单独列作参考 73.3 ± 3.5

更高层的几何结构有帮助，但主要增益还来自子目标与时间分解。此处的 16.7 是这个受控实验的数值，不能与另一组 flat LeWM 的 18.0 混成同一对照。

论文也报告局部子目标的代价与进度更单调：负 Spearman 相关性约 0.89–1.00，完整长程目标约 0.48–0.75。更平滑的代价解释了一部分优化收益，却不能单独解释全部成功率差距。

4.3 高层会自动学到任务语义吗？

AntMaze 中，高层逐渐保留身体位置、减弱腿部姿态；FourRoomDistractors 中，能够弱化干扰物而保留自身位置。这里存在明显的频率分离：控制相关状态与高频干扰容易分开。

Push-T、Cube 与 DROID 并不都出现同样清晰的抽象趋势。原文没有证明高层已经普遍获得语言语义、任务阶段或对象事件。Push-T 在三层及更深设置反而退化；短轨迹经过层级下采样后，三层、四层每 epoch 见到的有效转移分别只有 flat 模型的 58% 和 14%。层数比较也必须考虑训练样本量变化。

4.4 DROID 指标的边界

DROID 部分评估的是离线开环规划路径的 Fréchet fidelity：以不动作为参照，比较规划轨迹与专家轨迹的 Fréchet 距离。可概括为

Fidelity=100⋅dF(zero,expert)−dF(plan,expert)dF(zero,expert).

0 对应不动，100 对应专家轨迹，负数表示比不动更差。它不是实机闭环任务成功率；把这部分写成“已完成真实机器人部署验证”会超出论文证据。

5.Takeaways:

5.1 分层记忆应先说明保存的内容

这篇工作适合指导后续多尺度记忆，但迁移时需要补上新的证据。短期、长期两个名字本身不能构成创新；应说明短期层保存接触、局部运动和遮挡变化，长期层究竟保留对象持久状态、任务阶段还是关键事件，以及这些信息如何被策略读取。

以下属于后续研究设计，尚未由原论文验证：

  1. 在相同历史长度、token 预算、参数量与训练步数下，对照共享空间的多速率记忆和独立空间的分层记忆，分离时间采样与表征抽象的收益。
  2. 比较固定更新、预测误差触发更新、任务相关事件触发更新，统计写入频率、保留内容和过期状态，避免把低频更新直接称为高级抽象。
  3. 在背景切换、相机运动和对象状态变化中检查记忆内容，加入动作相关的预测约束，并验证它是否真正防止只保存场景身份。
  4. 用历史删除、对象状态替换和阶段切换实验，检验潜空间探针结果是否对应动作决策变化，最后再看任务成功率与计算成本。

5.2 局限性 & 未来工作

H-JEPA 证明了学习层级表征能够帮助特定任务的长程规划，也揭示了世界模型偏好“容易预测的信息”的风险。它没有直接解决部署中的持续记忆、语言条件控制与记忆读写问题。

对当前研究最值得借鉴的，是它的对照实验逻辑：把时间尺度、表征空间和规划方式拆开验证。这样才能说明新增记忆结构究竟解决了什么，而不是只展示一个更复杂的系统。
