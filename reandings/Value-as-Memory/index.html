Value as Memory: Online Value-Guided Post-training for General Robot Policies

这篇工作把近期 value 预测作为任务进度记忆输入策略，使机器人区分外观相近、但下一步动作不同的状态。它同时提出从离线示范到在线自主学习的后训练系统。对 JEPA + memory + VLA 方向，最有价值的启发是：记忆不只需要描述世界，还应帮助判断任务正在推进、停滞还是回退；但 value 是受策略和数据影响的估计，不能直接当作真实阶段标签。

工作类型(首次/改进)技术路线创新点日期
改进π0.5 + value cache + online post-training进度记忆缓解动作歧义 + 离线到在线数据复用2026-10-15

论文：arXiv v1；项目主页。本文核对截至 2026-10-25 的公开版本及原文附录。下文简称 VaM。

1.What？

VaM 将 value 从训练阶段的评价信号，变成部署阶段策略可以读取的历史信息。系统包含 action expert 和 value expert：前者生成动作块，后者根据近期视觉历史估计任务进展。过去已经计算完成的 value 被缓存，与图像历史、本体状态一起输入 action expert。

这里有两条不同的作用路径：

value 的用途 作用阶段 具体作用
计算 advantage、给动作数据打标签 训练 支持从不同质量的经验中提取策略
value cache 作为策略观测的一部分 训练与部署 提供近期任务进度及其变化信息

论文的记忆贡献主要来自第二条。仅仅使用 critic 做数据筛选，不能等同于让策略拥有了 value memory。

2.Why？

长时程操作中，外观接近的状态可能要求完全不同的动作。例如折叠衣物时，相似形状可能对应尚未折好、折好后松开、失败后准备重试。当前画面没有完整揭示过程，有限视觉历史也未必容易从高维变化中提取任务进度。

VaM 针对这种 soft aliasing：策略输入很相似，应该执行的动作分布却相差很大。近期 value 序列提供了一条低维的时间线索：这个状态是逐渐接近完成，还是一直停滞，抑或刚刚出现了退步？

与此同时，部署策略变化会带来新的失败状态。如果 value 长期停留在示范数据分布，错误进度就会成为错误记忆。因此本文把缓存机制与持续的在线后训练放在同一系统中研究。

3.How？

图源：原论文 Figure 2。上半部分为训练、采集和数据混合流程；下半部分为视觉历史、历史 value 与动作专家的连接。

3.1 从分布式 value 得到标量进度信号

value expert 输出固定支撑点上的 categorical distribution。设 K=256 ，支撑位于 [0,1] ：

pψ(vk∣htV),V^t=∑k=1Kvkpψ(vk∣htV).

初始化时，用成功示范中的归一化时间 t/T 构造高斯进度标签；进入 warmup 和在线学习后，使用稀疏任务奖励进行 TD 训练，成功终止得到正奖励，其他步骤为 0。

因此，这个标量先从示范时间进度获得初始化，再被部署经验校正为与回报相关的估计。它不等于真实任务完成百分比，也不能无条件解释成校准后的成功概率。分布输出同样不自动等同于模型认知不确定性。

3.2 缓存过去的 value，避免等待当前预测

在部署轮次 k ，固定使用上一轮完成训练的 value snapshot Vψ(k−1) 。value 预测与动作生成异步进行，因此当前时刻的 value 尚未就绪时，策略读取的是此前的结果：

ct(k−1)=(V^ψ(k−1),t−Hπ,…,V^ψ(k−1),t−1).

策略的完整输入为

xtπ=(htπ,st,ct(k−1)),

其中 htπ 是视觉历史， st 是本体状态历史。实现采用 GRU 编码过去 value 与本体状态，将最终 hidden state 接在视觉 tokens 后。它保存的是一段随 episode 更新的进度信息，不能与节约 Transformer 重算的 KV cache 混为一谈。

附录设置中，策略历史 horizon 为 4，value expert 的视觉历史为 2，观测历史 stride 为 30 个环境步。这些 horizon 指采样历史长度，不能直接解释为原始控制流中连续 4 帧。

3.3 网络与部署成本

action expert 继承 π0.5 的完整架构和预训练参数，包括 PaliGemma-2B 视觉语言骨干与 300M action transformer。value expert 则把 π0.5 原有的 300M action transformer 用作自己的视觉语言骨干，结合 temporal-spatial history attention、readout token 和 categorical value head。

异步执行避免策略等待同一时刻的 value，但 value expert 仍然需要额外计算和资源。论文报告的训练系统时间收益，也不能用来代替部署延迟与显存测量。

3.4 为什么缓存有助于缓解动作歧义？

设两个状态的视觉与本体表征距离为 ϵobs ，目标高优势动作分布之差为 Δa=W2(μ1,μ2) 。若策略在局部满足 L -Lipschitz 条件，则存在下界：

maxi∈{1,2}W2(π(⋅∣zi),μi)≥12(Δa−Lϵ)+.

输入太接近，而要求的动作差异很大时，平滑策略难以同时满足两者。加入缓存后的表征距离为

ϵπ=ϵobs2+∥c1−c2∥22.

如果 value 历史不同，就可能拉开两个状态，减弱上述歧义下界。这是一个有条件的解释：它没有保证缓存一定准确，没有保证训练必然找到正确策略，也没有证明加入有限标量历史就使环境完全可观测。

3.5 advantage conditioning 与四阶段训练

训练时，value 还用于构造多步 advantage，可概括为

At=Rt,H+γH(1−d)Vt+H−Vt,

其中 Rt,H 表示窗口内的折扣奖励， d 表示终止。随后按 advantage 分位数得到高／低优势标签，附录中阈值参数 ρ=0.70 。动作专家学习 advantage-conditioned flow matching，推理时通过高优势条件与 classifier-free guidance 提取动作策略。

完整流程分为四步：

  1. Offline expert demo initialization：示范行为克隆初始化动作专家，归一化时间标签初始化 value。
  2. Offline RL warmup：部署初始策略采集 rollout 与人工干预，训练两个专家适应失败、卡住与恢复状态。
  3. Online DAgger：在部署过程中继续收集人工干预与 rollout，持续更新模型并发布下一轮 snapshot。
  4. Learn from Experience，LfE：停止新增人工干预，继续从自主 rollout 学习，同时复用此前收集的干预、示范和经验。

warmup 对人工接管前的失败前缀标记终止且奖励为 0，同时保留完整 rollout 的最终结果及接管后的恢复信息。前缀与完整轨迹不是二选一：它们分别提供“此前已卡住”和“经过恢复最终成功”的监督。

数据混合也区分两个专家：动作训练复用示范、历史干预和当前 rollout；value 训练还复用历史 rollout。LfE 没有新增人工干预，不等于其训练完全没有使用人工数据。

4.实验结果

4.1 三个真实机器人任务

4.2 value cache 对最终成功率的影响

原文 Table 1 汇总最后三个在线检查点的成功率，单位为 %；误差为这些检查点之间的样本标准差，而不是独立训练种子的标准误：

方法 Box Assembly Laundry Folding Magnetic Bus Assembly
VaM 96.7 ± 2.9 88.9 ± 10.2 76.7 ± 5.8
无 value caching 81.7 ± 2.9 48.9 ± 30.1 43.3 ± 5.8
无 offline RL warmup 81.7 ± 7.6 60.6 ± 18.3 50.0 ± 10.0
RECAP 71.7 ± 16.1 64.4 ± 7.7 43.3 ± 5.8

三个任务相对无缓存版本平均提升 29.4 个百分点。若统计全部 LfE 检查点，平均差距为 31.3 个百分点，两个数值使用不同汇总窗口，不能混用。

主要消融在各自策略采集的数据上执行训练，而不是完全固定同一批轨迹后只切换部署输入。因此它反映缓存与在线学习共同产生的系统效果，不应全部归因于一次前向传播中的输入变化。

4.3 记忆内容的质量同样重要

作者固定最终的动作专家，只替换 value snapshot：

value snapshot Box Assembly Laundry Folding Magnetic Bus Assembly
仅示范初始化的 value 80.0 71.1 40.0
warmup 后的 value 85.0 68.9 50.0
完整在线更新后的 value 96.7 88.9 76.7

这是比“加不加记忆”更有诊断意义的实验：即使缓存接口与动作模型不变，过时 value 仍显著影响效果。缓存的存在并不保证缓存内容正确。

4.4 恢复能力与训练效率要分别解读

盲评统计的恢复事件成功率中，VaM 与无缓存版本分别为：Box Assembly 54.5% / 50.0%，Laundry Folding 86.4% / 58.8%，Magnetic Bus Assembly 33.3% / 7.4%。分母是需要恢复的事件数，同一 episode 可以有多个事件，这些数字不是整条任务成功率。

在匹配训练梯度步数与数据预算的在线／离线比较中，在线系统在 LfE 后平均提升 32.8 个百分点；采集、value 训练与动作训练并行，使平均每梯度步的实验总耗时降低 57.8%。例如 Box Assembly 的在线更新轮数为 16，离线为 2，即同等梯度预算下 8 倍迭代次数。

这些指标回答的是数据反馈频率与训练系统效率。57.8% 不是动作推理延迟降幅，32.8 也不能与缓存带来的 29.4 相加成一个总收益。

5.Takeaways:

5.1 世界状态记忆与任务进度记忆应承担不同职责

JEPA 表征更直接地描述场景及变化，VaM 则为“这些变化使任务推进了多少”提供监督。物体移动可能是成功推进，也可能是误操作；视觉预测误差升高可能来自关键事件，也可能只是腕部相机运动。后续研究需要把世界变化与任务相关性联系起来，而不是将两个模块简单拼接。

VaM 的低维缓存也提醒我们：任务进度是一类值得保存的信息，但一个 value 无法完整表示对象身份、隐藏物体位置或不可逆事件。它更适合作为记忆读写的辅助线索，而不是替代所有场景记忆。

以下属于后续研究设计，尚未由原论文验证：

  1. 在 JEPA-WAM 基线上比较视觉记忆、进度记忆和联合记忆，固定模型容量、历史预算及训练数据，分别测量动作正确性和任务成功率。
  2. 保持当前观测不变，交换历史与 value 序列，检查策略是否依赖真实的过程证据，而不是只利用 value 与示范时间的相关性。
  3. 对照准确、过时、打乱的 value 以及纯时间输入，分离语义进度、模型误差和执行时间的影响；同时检查失败恢复和阶段回退。
  4. 若只在模仿学习设置引入进度预测，需要独立验证其有效性。本文的收益建立在 warmup、在线经验与 value 适配之上，不能直接承诺同样收益会迁移到纯离线 VLA。

5.2 局限性 & 未来工作

缓存依赖 value 估计质量，估计偏差、异步滞后和部署分布变化都可能让错误信息持续影响策略。有限历史也无法覆盖所有长程依赖，而额外 value expert 的资源开销需要实测。

我更关心的研究问题是：如何让记忆同时保存“世界中发生了什么”和“这些事件改变了任务的哪个状态”，并用受控干预证明它们确实帮助预测与动作，而非只提高训练数据的拟合程度。
