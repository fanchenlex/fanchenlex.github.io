T²Mem: Learning Test-Time Memory for Robotics

这篇工作把 episode 历史写入 VLA 内部的快速权重，再用专家动作监督训练“如何记”和“如何用”。对 JEPA + VLA + Memory 方向，最值得关注的是观测驱动的记忆接口、交替记忆—策略学习，以及用冲突记忆替换检验历史是否真正参与决策。记住过去并不等于理解过去如何变化，原文在物体交换任务上的不足恰好暴露了这一区别。

工作类型(首次/改进)技术路线创新点日期
改进π0.5 + fast-weight memory + test-time training观测语义接口 + 交替学习 + 自适应写入2026-09-29

论文：arXiv:2609.36720v1 · 项目主页。本文依据本地原文及阅读笔记整理；下文的研究设计与原文结果分开说明。

1.What？

T²Mem 在预训练 π0.5 的视觉语言模型（VLM）与动作专家（Action Expert，AE）之间加入一条参数化记忆通路。它保留当前观测到 AE 的原有连接，同时让 AE 读取从历史中恢复的信息。

记忆不是不断追加的历史图像或 token，而是一组在 episode 内持续更新的神经网络参数 Wt 。每次新 episode 从学习得到的 W0 开始，旧 episode 的快速状态不会直接保留到下一次任务。

对象 在训练中承担什么职责 部署时是否变化
策略、接口、Q/K/V 投影、融合门控和初始化 W0 等慢参数 学习如何形成、读取和使用记忆 固定
episode 快速权重 Wt 保存当前轨迹的历史关联 根据观测进行自监督更新
专家动作 通过外层动作损失塑造记忆机制与策略 部署时不需要

所以，test-time training 在这里不是部署时重新微调整个 VLA，也不是从测试时奖励学习策略。发生在线更新的是专门的记忆状态。

2.Why？

被遮挡物体的身份、已经重复的动作次数、演示中的操作顺序，都无法始终从当前图像恢复。论文将记忆依赖任务写成：在相同任务分布和交互预算下，最优历史条件策略的期望回报高于最优当前观测策略：

supπ∈ΠhistJ(π)>supπ∈ΠcurrentJ(π).

但增加历史访问能力只解决了“过去是否可用”，没有解决“保存的信息是否对动作有用”。若在线记忆只学习重建视觉关联，它也能记住背景、纹理和无关运动；若只从 AE 表征写入，又容易过度依赖动作延续模式。

T²Mem 的问题因此有两层：从观测中建立能够持续读写的内部记忆，以及让动作监督决定这套机制最终为控制保留什么信息。后者是我认为比单独加入 TTT 更值得研究的部分。

3.How？

3.1 在 VLM 与 AE 之间提取记忆，而不是直接累积动作历史

图源：原文 Figure 2。记忆通路与当前视觉语言信息通路并存。

每层使用可学习的 interface tokens，对 VLM 的视觉语言特征 Zt 做 cross-attention，得到紧凑摘要 Ut 。独立投影随后构造：

Qt=Utθq,Kt=Utθk,Vt=Utθv.

interface 的 query 只允许访问有效的 VLM keys，屏蔽 action、proprioception 和其他 interface tokens。这里限制的是记忆接口的取证来源，AE 自身仍保留本体状态和动作上下文。这样可以减少“把动作直接写入，再靠动作外推降低模仿损失”的捷径。

原文使用 16 个、宽度为 1,024 的 interface tokens。VLM 与 AE 各有 18 层；各层都分配记忆模块，但接口更新只能被后续层消费，因此有 17 层有效参与这条记忆通路。不是在同一层已经完成注意力计算后，再让它读取刚更新的接口。

3.2 先读取，再用自监督损失写入

读取当前 episode 的记忆：

Rt=fWt(Qt).

通过通道级门控，将历史读出与当前摘要融合：

U~t=Ut+tanh⁡(α)⊙Rt.

经过后续 residual 与 feed-forward 变换，增强接口为 AE 提供注意力上下文。门控初值较小，用于减轻新增记忆对预训练能力的扰动；它与后面的写入强度系数不是同一个机制。

写入则最小化当前观测构成的关联重建误差：

Lmem,t=mean[(fWt(Kt)−Vt)2], Wt+1=Wt−wtηtβt∇WtLmem,t.

其中 wt 是写入调度的二值掩码， ηt 是经过曲率校准、包含可学习正乘数的步长， βt 调整本次写入幅度。

同一观测采用 read-before-write。 当前动作读取 Wt ，这次写入产生的 Wt+1 影响后续决策。推理时，动作块的多次去噪读取同一个固定快速状态，不会每执行一次去噪就重复写入。

标准评估预测 64 个动作、执行 32 个再规划，写入 stride 为 16 个物理环境步；执行中点的观测可以写入记忆而不触发重新规划。它们不是优化器步数或扩散去噪次数，也不是每个控制帧都必然写入。

3.3 用外层动作损失学习“怎样记忆”

内层 Lmem 只利用观测进行关联学习。外层使用专家动作的 flow-matching 损失，梯度通过记忆读取及保留的历史写入路径，更新接口、投影、初始化和策略参数。

这两种学习信号不能混为一谈：

学习信号 直接优化的对象 需要什么监督
内层关联重建 当前 episode 的快速状态 观测生成的 K/V
外层动作预测 策略与记忆机制的慢参数 专家动作

因此，“部署时不需要记忆标签”不等于整个机制没有任务监督。T²Mem 依靠离线专家动作，让在线自监督更新最终服务于动作预测。

3.4 交替记忆—策略学习

图源：原文 Figure 3。冻结指慢参数，而不是停止 episode 快速状态的演化。

先进行 Stage 1 无记忆策略适配，再反复交替两个阶段：

  1. Stage 2A，学习记忆：固定 VLM/AE，训练记忆接口、读写投影、初始化、步长乘数和融合门控。动作损失穿过冻结的 AE，仍能训练其上游记忆。
  2. Stage 2B，学习使用记忆：固定记忆机制的慢参数，更新 VLM LoRA、AE 及相应输入输出投影。快速权重继续读写，策略学习结合当前信息与历史信息。

附录参考设置先适配 20,000 步，之后每个交替阶段各更新 500 次。视觉编码器和基础 VLM 权重保持冻结，VLM 侧的适配通过 LoRA 完成；图中的“VLM 更新”不应解释成解冻整个视觉语言基座。

交替的动机是给每一方一个相对稳定的学习对象。若记忆表示与策略同时变化，两者会不断适应对方变化后的输入和梯度。原文支持其在指定任务及训练预算下的有效性，没有证明联合训练在所有设置中都不可行。

3.5 自适应写入：抑制反复强化，但不是直接检测任务事件

令 gt=∇WtLmem,t ， ut=−gt ， Δt=Wt−W0 。原文逐 head 计算更新方向与累计参数变化的对齐度，以及归一化残差：

at=⟨ut,Δt⟩max(∥ut∥∥Δt∥,10−12), rt=clip[0,1](RMS(fWt(Kt)−Vt)max(RMS(Vt),10−8)).

然后定义

nt=1−clip[0,1](at),zt=nt1+rt2, βt=0.1+0.9(3zt2−2zt3).

若更新继续沿累计变化方向推进， at 接近 1， βt 被压到 0.1；当对齐度不为正且残差较高时，可以保留更大的写入幅度。附录另行处理零梯度、零位移的退化情况。

这里有三点需要注意： βt 本身不学习，且与曲率校准均使用 stop-gradient；其最小值为 0.1，不负责把一次已调度写入完全关闭；高残差也可能来自噪声，不能直接解释成动作相关事件。消融中的 βt=1 仍保留步长校准，不等于恒定学习率。

4.实验结果

4.1 RoboMME 上的整体表现

16 个任务覆盖 Counting、Permanence、Reference 和 Imitation。每个任务使用 50 个测试 episode、3 个评估 seed，共 150 条 rollout，最后对任务做宏平均。

方法，原文 Table 1 平均成功率 / %
π0.5 17.93
π0.5 + past actions 19.73
Stage 1，无记忆适配 16.38
RoboMME TTT-Expert 22.35
FrameSamp-Modul 44.51
MemER 42.38
T²Mem 56.83

相对表中 π0.5 提升 38.90 个百分点。表内已有方法的分数直接引用 RoboMME 原文，并非作者在完全相同训练配方下统一复现；部分方法还使用额外子目标标注或外部模型，Oracle 则有特权信息。这个比较支持整体有效性，不能替代控制信息访问与训练预算的实验。

4.2 接口位置与训练方式都有影响

下面是独立单任务训练的消融，不是上表多任务模型的逐任务切片：

设置，原文 Figure 4 VideoUnmask / % MoveCube / %
无记忆 23 28
AE 内的 RoboTTT-style 集成 30 26
同时更新记忆与策略 30 28
T²Mem 接口 + 交替学习 84 71

架构对照保留交替训练、自适应写入与相同步数，因此更直接地支持从 VLM 语义接口提取记忆。不过，RoboTTT-style 是本文实现的 AE 侧集成对照，不能视为对完整 RoboTTT 预训练系统的复现结论。

自适应写入的实验固定写入节奏和步长校准，在 20 条 VideoUnmask Hard 轨迹中回放后续 300 帧，测量早期 K/V 绑定的重建误差。相比 βt=1 ，误差降低 18.8%–46.9%。它证明这组回放设置中干扰更小，没有证明该缩放函数是唯一最优设计，也不是直接报告任务成功率提升。

4.3 比“加了记忆有效”更重要的三组干预

禁用写入。 保留初始化与读取，只关闭 episode 更新，VideoUnmask、SwingXtimes、MoveCube 的成功率分别下降 82.67、64.67、41.33 个百分点。这些诊断使用各自的任务检查点。

替换记忆内容。 在目标环境、指令和扩散 seed 不变时，用正确示范、冲突示范或空示范构建记忆。50 对目标、两个方向、3 个 seed，共 300 次评估，结果分别为：

示范记忆 成功次数
正确 300 / 300
冲突 1 / 300
空记忆，即学习得到的 W0 101 / 300

冲突记忆比空记忆更差，说明决策依赖具体内容，而非仅依赖额外参数或一个“存在记忆”的标志。

限制写入时机。 在同一个 66 帧示范前缀内，遮挡前 8 次写入达到 76.67%，遮挡后同样 8 次写入只有 20.67%；前者与完整前缀的 16 次写入相同。它定位了有效证据出现的区间。但该协议截短了部分 Hard 示范，不能将 76.67% 与另一协议的 84% 直接比较来判断多写是否有害。

4.4 效率与成本

原文在 RTX A5000、batch size 1 下进行预热和同步计时：

方法 记忆相关阶段 / ms 单次推理 / ms
T²Mem 7.7 146.6
FrameSamp-Modul 148.9 440.0
MemER，主文所用生成预算 9,890.9 10,135.6

测量排除初始化、编译、RPC、仿真与动作执行，且外部规划器生成预算影响很大。146.6 ms 是受控工作负载中的单次推理时间，不能直接当作包含硬件执行的闭环控制周期。

固定容量也不等于零成本：增加约 67.90M 参数，其中学习到的快速状态初始化占约 9.529M；每条 episode 分配的 FP32 快速状态为 36.35 MiB，不包括注意力缓存与激活。原文报告训练使用 32 张 H200、48 小时，也需要纳入复现预算。

5.Takeaways:

5.1 与当前 JEPA + VLA + Memory 主线的关系

我在笔记中最关注的判断是：记忆应受到未来决策的约束。 T²Mem 给出了动作监督穿过内部记忆的具体实现，而 JEPA-WAM 提供未来潜在表征监督。两者分别强调“过去的信息怎样帮助动作”和“当前表征怎样解释未来”，可以共同指导记忆设计，但直接拼接并不足以证明创新。

尤其要区分两类误差：本文的 fW(K)−V 是记忆关联的重建误差；世界模型预测未来与实际未来之间的差异是转移预测误差。二者的含义、时间索引和噪声来源不同，不能换一个名字就作为同一事件信号使用。

以下属于后续研究设计，尚未由原论文验证：

  1. 固定策略基座、数据、历史预算和参数规模，对照 recurrent tokens、TTT 快速权重和显式历史帧，先确认是否解决同一种信息缺失。
  2. 分别使用动作损失、潜空间预测损失及二者联合训练记忆，检验预测监督是否保留了后续动作真正需要的对象状态，而非只提高表征可预测性。
  3. 沿用冲突记忆替换、禁用写入和证据窗口干预，并加入物体交换、不可逆事件与阶段回退，区分静态线索回忆和动态状态追踪。
  4. 对预测误差触发写入，加入相机运动、背景变化和无关物体扰动，测量无效写入与漏写关键事件，而非只统计平均写入次数。

5.2 局限性 & 未来工作

T²Mem 在物体交换任务上仍明显弱于简单回忆：VideoUnmask 为 88.00%，VideoUnmaskSwap 为 29.33%；ButtonUnmask 与其 Swap 版本分别为 59.33% 和 20.00%。这些差距提示记忆内容保留后，系统还需要更新对象—位置关系。基础策略跨时间推理不足是作者的解释，尚不能仅凭分数排除其他因素。

任务成功也混合了记忆决策与精细控制。InsertPeg 达到 36.00%，作者观察到模型能接近正确目标，却在最终插入失败。因此后续实验应分别统计目标选择、状态判断和最终执行结果。

对我而言，值得继续追问的不是快速权重能保存多长历史，而是：有限记忆能否持续更新“世界当前是什么状态”，并用干预证明这些状态确实改变了正确动作。
