Embodied Interpretability: Linking Causal Understanding to Generalization in Vision-Language-Action Models

这是第一篇我看到的关于VLA可解释性的文章，感觉对于以后的研究会有帮助，可以启发我从可解释性的方面考虑问题和实验设计。

首次 VLA Interpretability 2026-06-10

1.What？

这篇论文不是提出一个模型而是研究具身领域关于可解释性的这个具体问题。作者通过提出两个核心指标：Interventional Significance Score（ISS）和Nuisance Mass Ratio（NMR）从而量化这个可解释性。
作者提出的核心假设是：OOD 泛化能力≈是否依赖因果相关视觉证据 也就是说泛化差，不一定只是模型“能力不够”，有可能是模型“看错东西了”。

2.Why？

可解释性对于带有LLM的研究领域都很重要，因为LLM本身是一个黑盒，那么如何让我们提出一个方法后能够通过一些方法验证我们提出的方法是不是有效，这个很重要。
把“解释”从相关性变成干预这是整篇论文最关键的一步。过去很多 interpretability 方法：看 attention。
比如模型看到：桌子 杯子 机械臂 背景```Attention 告诉你：背景： 0.40杯子： 0.30机械臂：0.20桌子： 0.10 于是我们说 “模型比较关注背景。”但是这里有一个问题：“模型关注它” ≠ “它造成了这个动作”。这两个概念完全不同。
论文也明确指出，attention 可以告诉你模型“focus 在哪里”，但不能证明这些区域是动作的causal necessary evidence。

举一个非常重要的区别假设：背景是蓝色机械臂在右边杯子在左边模型每次看到：蓝色背景 → 向左抓于是 attention 很可能特别关注蓝色背景。但问题是：蓝色背景真的导致“向左抓”吗？很可能不是。如果你把背景改成：红色背景杯子和机械臂全部没动：正常的、真正理解任务的模型应该：动作几乎不变。但是如果这个模型突然：动作大幅变化那说明：它依赖了背景这个 nuisance feature。这就是作者认为真正的“因果解释”应该做的事情：**动输入，看 action 有没有跟着动。**而不是看模型有没有把 attention 放在那里。

这就是论文从“attention interpretability”转向“interventional interpretability”的核心思想。

3.How？


核心方法 1：Interventional Significance Score（ISS）

这篇论文真正提出的方法是：ISS：Interventional Significance Score可以把它翻译成：干预显著性分数

它要回答**如果我把视觉区域 X 改掉，模型的动作到底改变了多少？**改变越大：这个区域对动作越有因果影响

ISS 的思路其实非常朴素原始输入：图像 → VLA → action

假设图像中有一个视觉 token: “杯子”

我们构造一个 counterfactual：原图：桌子 + 杯子 + 机械臂 + 背景

把“杯子”这个 token 替换掉：干预：桌子 + [杯子被替换] + 机械臂 + 背景

然后重新跑模型。比较： aoriginal 和 aintervention 如果：∥aoriginal−aintervention∥2 很大说明这个 token 很重要。如果几乎没变说明模型其实不太依赖它。论文最终把这种干预影响定义成 KL divergence，并累计整条 expert trajectory 的影响。

为什么论文不直接把 token 设成 0？这是一个非常细的设计点，但很值得注意。如果直接：xi=0 可能产生一个根本不存在于训练分布中的 feature。比如：正常视觉 token→突然变成全 0→模型看到奇怪的 OOD 表示

这时候 action 变化可能只是因为你把输入弄坏了而不是因为这个 token 本来就重要。所以作者采用training distribution 上的 modality-specific mean embedding即把被干预 token 替换成该模态的平均 embedding。视觉 token 用视觉均值：μi=EDvis[v] 语言 token 用文本均值：μi=EDtext[l] 这样更接近把这个信息拿掉而不是塞给模型一个完全奇怪的输入。

但是把每个 token 单独干预，计算量太恐怖了假设：3 个 camera× 16×16 visual tokens× 很长 trajectory```如果每一个 token 单独干预：T×3×162 次 forward。完全不现实。于是作者使用：Monte Carlo Random Masking

它到底怎么随机 mask？每次随机生成：Mk∼Bernoulli(p)

可以简单理解成：杯子 ✓机械臂 ✓背景 ×桌面 ✓

然后保留的区域：原始图像 ;被 mask 的区域：blurred image

公式大致是：V~=V⊙M+Vblur⊙(1−M)

也就是说不是硬删除，而是把随机选中的区域替换成模糊版本。然后模型重新预测 action：a^k 和原始 action：a∗ 计算：δk=∥a^k−a∗∥22 再把这个 action difference 归因回被 mask 的区域。论文 Algorithm 1 就是在做这个过程。

这个时候 ISS heatmap 就出来了最终每个视觉 token 都会有一个分数

背景 0.02机械臂 0.45杯子 0.38桌面 0.03

│ │
│ 🔴杯子 │
│ 🔴 │

└────────────────────────┘

它得到的是哪些视觉区域真的会改变模型 action？这比 attention map 更接近causal attribution

为什么论文还要用 Teacher Forcing？这里非常重要。

假设：原始模型：t1 → t2 → t3 → t4 干预模型：t1’ → t2’ → t3’ → t4’

如果第一步干预让模型动作稍微不同：t1 ≠ t1’那么后面状态也不一样：t2 ≠ t2’t3 ≠ t3’t4 ≠ t4’最后你发现 action 差很多。但你不知道是因为这个 visual feature 本身很重要，还是因为第一步的小误差滚雪球导致整条轨迹分叉。这会严重污染 attribution。所以作者采用Teacher Forcing即比较原始和干预输入时，都固定在 ground-truth / expert trajectory 上。这样测量的是同一个决策状态下，改变视觉证据会对 action distribution 产生什么影响？”而不是改输入之后整条轨迹最终会变成什么样。论文明确说明这一点是为了避免 trajectory divergence 累积误差。

第二个核心指标：Nuisance Mass Ratio（NMR）

ISS 解决每个区域对 action 有多重要？但是研究真正想问的是“模型是不是在依赖错误的东西？所以作者继续做了一步。他们把视觉空间划成三类：① Action-Critical Region：Ωact 比如：- robot arm - end-effector 即动作发生的主体。 ② Environmental Support Region：Ωsup比如：- cup - table - rack - 任务相关物体 这些不是机器人本身，但对于执行任务是必要的。 ③ Nuisance Region：Ωnuis比如：- 墙壁颜色 - 背景纹理 - 光照反射 - 无关物体 即：理论上不应该决定 action 的东西。这个三分法是论文后面的理论基础。

这就引出了一个概念：Causal Markov Blanket

作者借用了因果图模型里的Markov Blanket意思简单理解就是如果我要预测一个变量，哪些信息是最小且足够的？对于 robot action：M(a)=Ωact∪Ωsup 也就是说机械臂 + 任务相关环境就应该已经足够决定合理 action。那么：Ωnuis 原则上不应该具有真正的 causal influence。如果你的模型却高度依赖 Ωnuis 这就是 causal misalignment。换句话说模型学到的不是“世界真正怎样影响动作，而是“训练数据里什么经常和动作一起出现。

NMR 到底怎么算？ISS 会产生一张 saliency map。然后取Top-k% 最重要区域比如 Top-10%。

假设模型最关注的区域里：杯子 40% 机械臂 30% 桌子 20% 背景纹理 10% 那么：NMR@10=10% 意思就是模型 Top-10% 的 causal attribution 里，有 10% 落在 nuisance 区域。论文正式定义的是：ρISS(k)(Ωnuis)=Top-k ISS regions 与 nuisance region 的交集占比

NMR 最直观的解释

机械臂 █████
杯子 █████
目标位置 ████
背景 ▏

那么：NMR→0 这意味着模型几乎不依赖无关背景。有 spurious correlation 的模型

背景纹理 █████
墙壁颜色 ████
阴影 ███
杯子 ██
机械臂 █

那么：NMR→高说明它的决策逻辑已经“跑偏”了。论文明确把 NMR 解释为 causal misalignment 的量化指标。

作者不是只证明“能解释”如果论文做到“看，这张 heatmap 看起来挺合理。”其实意义没那么大。真正重要的是这个解释指标和泛化能力有没有关系？也就是： NMR⟶?OOD Success

实验发现：NMR 越高，泛化越差他们在 AGNOSTOS 上测试 π0.5。训练3600 episodes测试575 episodes测试分为：Seen训练过的任务。

U1有部分语义重叠。例如：相似物体 / 相似 action primitive

U2真正新任务： 既没有相同物体，也没有相同 action。

然后他们计算：NMR@k 和：Task Success 之间的 Pearson correlation。

最强的是：r=−0.77 在NMR@10 处取得。也就是**模型越依赖 nuisance feature，任务成功率越低。**这是整篇论文最重要的实验发现。

这其实改变了“具身可解释性”的目标以前Interpretability = “告诉我模型看了哪里“

作者认为 ISS 比 Attention 更合理：

作者做了两类实验：

  1. Robustness

给 nuisance region 加 Gaussian noise如果只是扰动无关区域，好的 attribution 应该保持稳定。他们比较：ISS，attention，token norm

结果：ISS 在 attribution stability 和 action consistency 上更好的 Pareto trade-off。
论文报告的一个对比点是 ISS 的 saliency cosine similarity 为 0.995，而 attention 为 0.959

  1. Fidelity

对 nuisance 区域做三种结构化干预：texture，geometric，patch

然后看saliency map 的变化和action MSE 的变化是不是同步。ISS 的 Pearson correlation 分别达到：0.78,0.64,0.72明显高于 attention 和 token norm。进一步的 unseen geometric intervention 上，ISS 的相关系数达到：0.79 而 attention 是：0.60 token norm 是：0.48所以作者的观点不是：attention 完全没用。而是：attention 主要描述“哪里有高响应”，ISS 则更接近“改变哪里会导致行为发生改变”。

同一个任务：“stack the other cups on the top of the red cup”

成功轨迹更多依赖：机械臂，end-effector，cups 失败轨迹则更容易依赖：background，texture，shadow

也就是说：**模型失败并不只是“没看清楚”，可能是“看错了”。这两者是完全不同的问题。这对机器人研究很重要。因为如果你只是做failure analysis = 看模型哪里走错了。你只能知道“动作错了。”但是 ISS 能进一步问：“为什么错？因为它把注意力/因果依赖放到了错误的视觉区域。”**这就开始接近 mechanistic diagnosis 了。

4.Takeaways:

后面实验可以通过这几个指标来研究评价可解释性

可以把“causal alignment”作为一种模型训练目标，而不只是解释工具

这篇论文主要把 ISS/NMR 当作：diagnostic tool不是直接用来训练模型。但这恰好留下了一个非常自然的研究方向。

例如：L=Laction+λLcausal让：Lcausal 惩罚：ISS(Ωnuis) 或者：NMR过高。那么你的模型就不只是：**“动作做对。”还被要求：“尽量通过正确的视觉证据做对。”**这个思想我个人认为比单纯attention regularization更有意思

“可解释性”可以反过来帮助数据集设计 这是我觉得很多人容易忽略的一点。如果你发现：某个 benchmark 的模型 NMR 极低。这不一定意味着模型特别聪明。可能意味着**任务太简单，没有明显的 spurious correlation。**相反，如果：background 一换模型就崩。说明数据集实际上存在：shortcut learning opportunity于是 NMR 可以帮助你回答：**这个 benchmark 到底有没有真正测试 causal generalization？**所以：Interpretability→Benchmark Diagnosis这是一个很有价值的方向。

总结

这篇论文不是在说：**“我们发明了一个更好的 heatmap。”**它真正做的是把一个很重要的问题提出得更清楚：**一个 VLA 如果在训练环境里成功了，我们怎么知道它是真的学会了任务，而不是记住了背景和纹理？**它的答案是：

第一步

对视觉证据进行干预。Change visual evidence→observe action change 得到：ISS

第二步

看模型最重要的区域里面，有多少其实是 nuisance。即NMR

第三步

验证：NMR↑⇒OOD Success↓

在论文实验里，NMR@10 和任务成功率达到了 −0.77 的 Pearson 相关。

所以全文可以浓缩成：Causal Attribution→Causal Alignment→Generalization

这条链我认为就是这篇论文最核心的思想。

对我自己的研究来说重点吸收的不是 ISS 这个具体公式，而是它背后的研究范式：

不要只问“模型成功了吗？”

不要只问“模型看哪里？”

而要问“改变什么信息，会改变它的动作？”

再问“它改变动作的依据，是不是物理任务真正需要的因素？”

局限性&未来工作：

还没有解决“完整的具身可解释性”.这个一定要看清楚。它现在回答的是：**哪些视觉特征影响 action？**但它还没有真正回答：**模型内部到底形成了什么世界模型？**更没有完整回答：**为什么这个视觉因素在物理世界中会导致这个动作？**所以：Visual causal attribution还不是：Full embodied causal understanding这是两件事。

1. Action distribution multimodal

现在 ISS 用 action MSE 近似 KL divergence，需要一定的 unimodal assumption。如果一个状态：向左走可以成功；向右绕过去也可以成功。那么两个 action mode 都合理。这时候简单的 MSE 可能把两个合法 mode 的差异错误地当成“因果变化”。论文明确指出，这会影响 multimodal / ambiguous long-horizon settings 下的 attribution validity。

2. ISS 现在很慢

最佳设置：N=100,p=0.3 总 latency 约：5.18s throughput：0.19Hz 所以它更适合：offline diagnosis而不是：online real-time control。

3. NMR 依赖 nuisance mask

如果你告诉模型：哪一块是 background。那当然很容易计算 NMR。但真实机器人世界里：谁来准确标记 nuisance？论文指出真实环境通常要依赖 segmentation，而 segmentation 本身就可能出错。

真正的“具身可解释性”最终应该到：

Observation→Internal concept/state→Physical causal model→Action

也就是说，不只是：“模型为什么动手？”而是：“模型内部认为世界是什么样、它认为什么因素会导致什么结果、这个内部因果模型如何产生动作？
