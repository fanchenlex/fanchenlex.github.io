MemBodied: Recurrent Associative Memory for Vision-Language-Action Models

这篇文章通过逐层关联矩阵记录交互历史，再单独保留固定的初始场景锚点，让 VLA 在观察到动作后果后更新记忆。它与我目前的记忆设计有明显重合：固定容量、初始参考、动作参与写入和门控更新都已有对应实现。对我的研究，更需要验证的是延迟 JEPA 监督能否改变记忆学会保留与修订的内容，并带来可定位的决策收益。

改进π₀ / π₀.₅ + 循环关联记忆逐层门控 delta 更新、suffix 记忆读出与固定初始场景锚点2026-09-23

1.What？

MemBodied 为 VLA 增加两条互补记忆路径：一条用关联矩阵记录回合中的交互，另一条用固定初始场景锚点保留最初的空间参照。每次策略调用读取这两类信息，生成动作块；收到下一次真实观察后，再将动作与后果写入矩阵。

组件 保存什么 是否跨策略调用保留 回合内如何变化
逐层关联矩阵 历史交互形成的潜在关联 是 根据新交互门控更新
初始场景锚点 初始多视角图像的压缩空间特征 是 固定
suffix memory token 当前调用中读取的关联内容 否 每次调用重新建立，在各层接收读出

持续记忆的载体是矩阵，memory token 是动作专家使用读出内容的接口。 这两个概念不能混用。

作者在五个 RMBench 历史依赖任务上得到 50.0% 平均成功率，无记忆 π₀ 为 6.4%；在三个真机任务上从 2/60 次成功提升到 16/60。本文没有额外世界模型或 JEPA 预测分支，读写参数由后续动作损失学习。[§3、§5]

2.Why？

动作 chunk 解决一次调用内的连续控制，无法自动保存下一次调用还需要的历史。机器人把积木移走后，当前图像不再说明原来应放回哪个垫子；交换两块相同积木时，相似的占位布局可能对应不同阶段；电池测试反馈消失后，还要记得此前哪些朝向组合已经失败。

这些任务存在时间上的状态混淆：相似的当前观察，需要依据不同历史选择不同动作。

历史处理方式 能解决什么 仍有什么问题
保留全部过去观察 能回看较完整的证据 上下文、存储和推理开销随历史增长
固定窗口 成本有界，容易实现 早期关键线索会离开窗口
循环 latent token 跨调用保留固定大小状态 信息经过反复变换，读写较隐式
历史 bank 与检索 可显式访问历史记录 需要额外的管理与读取流程

作者选择关联记忆：用固定大小矩阵保存 key–value 关系，让策略学习何时保留、写入和读取。这里的 gated delta rule 来自已有的关联记忆研究；本文将它用于连续机器人控制，并比较动作专家中的接入方式。[§2、附录 A.3]

另外，动态状态反复更新容易损失初始位置与物体分配。初始场景锚点专门保存这一类固定参考，使动态矩阵可以更多地记录之后的交互。固定容量本身已经存在于固定窗口和循环 token 中，本文更值得讨论的是读写方式，以及固定参考与动态历史怎样分工。

3.How？

3.1 每层一个关联矩阵

完整回合记忆记为 Et=(Mt,A) ，其中 A 是固定锚点，动态部分为：

Mt={St(l)}l=1L,St(l)∈RB×r×r.

L 是动作专家层数， B 是 batch size，主要实验关联维度 r=128 。每个回合开始时，矩阵重置为学习得到的初始状态 S0 ，锚点由该回合第一帧重建。

r=128 表示关联空间维度，不代表 128 条显式历史记录或 128 个可逐一取出的记忆槽。写入时在原矩阵中叠加或修订关联，不会向历史列表追加条目。每个样本的动态状态包含 Lr2 个标量，此外还要计算锚点与部署缓存的存储。[§3.1–3.2]

3.2 写入 value：动作摘要与后续视觉

在动作 at 执行后，获得新图像 It+1 和本体状态 st+1 。先用状态生成 query，对每个相机的视觉 patch 做 attention pooling：

et+1(c)=Attn(Wpqϕs(st+1),WpkXt+1(c),WpvXt+1(c)).

这里 Xt+1(c) 是第 c 路相机的视觉特征。平均各相机结果，再拼接动作块的求和摘要：

et+1vision=1C∑c=1Cet+1(c),yt=[et+1vision;∑h=1Hat,h], vt(l)=Wv(l)yt.

因此，每层写入的 value 同时包含动作信息与随后观察到的变化。视觉 patch 在 memory-value 路径上停止梯度，后续池化和投影仍可学习。[§3.2.1]

这里我认为有一个明确限制：动作求和会丢失顺序。两段不同动作可能有相同求和结果，不能据此认定这条写入路径完整编码了有顺序依赖的交互。LIBERO 中动作摘要与实际执行的对齐问题还需要单独检查，见后文。

3.3 写入 key 与两个门

第 l 层的写入 key 来自上次策略调用缓存的该层输出表示：

kt(l)=L2Norm[tanh⁡(Wk(l)ht,out(l))].

在 π₀ 中， ht,out(l) 对应状态 token 的层后表示。将它与交互表示 yt 拼接，得到保留门和写入门：

αt(l)=σ(Wα(l)[ht,out(l);yt]),βt(l)=σ(Wβ(l)[ht,out(l);yt]).

αt 控制旧关联保留， βt 控制新关联的修正强度。它们在更新式中构成对角矩阵，沿关联矩阵的行方向作用，不是每张图像一个“是否惊讶”的标量。[§3.2.2]

3.4 门控 delta rule 怎样修改已有内容？

省略层标记，先按保留门处理旧矩阵：

S¯t−1=Diag(αt)St−1.

再更新：

St=S¯t−1+Diag(βt)(vt−S¯t−1kt)kt⊤.

可以按下面的顺序理解：

  1. 用 αt 保留一部分旧矩阵。
  2. 用当前 key 查询旧关联，得到 S¯t−1kt 。
  3. 计算新 value 与旧查询结果之差，把这个修正写回当前 key 对应的方向。

其中 vt−S¯t−1kt 是关联内容的修正误差。模型此时已经看到了新观察，所以它不是未来视觉预测误差；两个门也不是根据这个误差大小直接设定的 surprise gate。

为理解更新性质，考虑两个门各维均为 1、key 为单位向量的情况：

Stkt=[St−1+(vt−St−1kt)kt⊤]kt=vt.

这说明一次更新可以准确修正当前 key 的关联。但对于另一个 query q ，同一理想条件下的读出变化为：

(St−St−1)q=(vt−St−1kt)(kt⊤q).

key 越相关，更新越可能相互影响。 这是从更新式得到的分析，论文没有证明矩阵中的多条历史绑定可以独立保存。状态大小固定，仍然会有干扰与容量限制。

3.5 从矩阵读取到 suffix memory token

在每层，用进入该层的状态 token 表示构造读取 query，再做矩阵读取：

qt(l)=L2Norm[tanh⁡(Wq(l)ht,in(l))],rt(l)=St−1(l)qt(l).

这里是连续关联检索，没有从历史列表中选出某张图像。π₀ 的动作专家 suffix 为：

[state token, memory token, H noisy action tokens].

读出投影到动作专家宽度，经过缩放和标量读取门，加入 memory token：

mt(l)=αmemrWm(l)rt(l),gt(l)=σ(Wg(l)ht,in(l)), xmem,t(l)←xmem,t(l)+gt(l)mt(l).

主要实验 αmem=256 、 r=128 ，显式乘数为 2。动作 token 随后通过 self-attention 使用读出内容。memory token 每次调用重新建立，矩阵才跨调用持续。[§3.3.1]

π₀.₅ 的状态在语言 prefix 中，没有独立 suffix state token，所以作者改用 memory token 的层前表示生成读 query、层后表示生成下一次写入 key。关联矩阵和初始锚点的分工保留。[附录 B.6]

3.6 固定初始场景锚点怎样接入？

作者将第一帧每个相机的 16×16 视觉网格平均池化成 4×4，再拼接相机特征：

A=Pool(X1).

每相机保留 16 个空间 token，三相机共 48 个，保存粗粒度初始布局。它不是单个全局摘要 token。

当前机器人状态先对当前各路视觉特征池化并平均，得到 zt ，再由它查询锚点：

ct=zt+WoAAttn(WqAzt,WkAA,WvAA).

锚点注意力维度 rA=64 。输出投影到动作专家宽度后，在动作 horizon 上重复，并融合到各动作输入的条件表示。[§3.4]

锚点在回合内不更新，也不拼接到 VLM prefix；动态关联读出则通过新增的 suffix memory token 接入。两条路径都没有把历史观察持续追加到原 prefix 中。

3.7 读写时序与动作监督

原文的因果顺序是：

Mt−1→ It,st,ℓ 读取at→执行It+1→写入Mt.

推理缓存上次调用的逐层隐藏态，以及最后一次去噪得到的动作块。新观察到达后，先完成上一次交互的写入，再用于后续策略调用。这样生成 at 时无法访问尚未发生的 It+1 。[§3.5]

训练时，每个样本包含连续的 N 组观察—动作对，相邻观察间隔一个动作 horizon。图像编码可在 batch 和序列维度并行，记忆状态按时间顺序传播。后续动作损失通过状态链训练早期写入：

Lact,t+k→St+k−1→⋯→早期记忆读写参数.

只使用策略原有动作目标，没有独立记忆预测损失。 “完整序列反向传播”指完整的训练采样序列，不意味着任意长度整回合都保留计算图。部署更新回合状态，不进行参数梯度更新。[§3.6]

LIBERO 部署还有一个值得复现时单独检查的细节。 每执行 5 步重规划，而训练记忆间隔是 50 步，因此作者维护 10 套轮换的循环状态：每次访问一套，同一套经过 50 个环境步再次被访问。

附录 B.3 明确说明，再访问时使用新观察和上次预测的完整 50 步 chunk 摘要，其中包含当时只执行 5 步后已被重规划替换的部分。因此：

上次预测的完整动作块≠两次观察之间实际执行的控制序列.

这是动作摘要与实际后果可能不匹配的问题，并非把未来真实观察泄漏给策略。对我实现的直接要求是记录两次真实观察之间实际提交给环境的动作，再与后果配对。这里的 10 套轮换状态也不是 10 个内容寻址的历史条目。

4.Takeaways:

4.1 收益来自持续状态，也取决于读写和接入方式

RMBench 五个任务每任务测试 50 次，成功率单位为 %。[Table 1]

相比无记忆策略，提高 43.6 个百分点；相比普通循环记忆，提高 33.2 个百分点。这支持“持续状态有用”，也说明仅有循环连接不足以解释完整模型的效果。

AS 把读取内容用于 attention query 与输出修正；H 保留这条读取方式，并增加慢速循环矩阵。它们与主版本比较的是完整记忆设计，尤其 H 同时改变了更新与读出，不能将结果完全归因于某一个接口选择。[附录 B.4–B.5]

本地 RMBench 对照共享 π₀、LoRA 设置与优化步数，但架构、batch 和计算开销并不全部相同。µVLA 的本地适配为 0%，只说明这一适配在本文训练方案下未成功，不能据此判定原方法无效。

MemBodied 接入 π₀.₅ 后平均 48.0%，论文引用的无记忆 π₀.₅ 为 12.4%。后者来自 RMBench 已发表结果，不是相同训练流程下重新训练的对照，因此更适合作为适配效果参考。

真机使用双 AgileX PiPER 和三相机，Put Back、Rearrange、Swap 每任务每模型 20 次。无记忆分别为 1/20、1/20、0/20；MemBodied 为 7/20、7/20、2/20，总计 16/60，即 26.67%。相对提升明显，但绝对成功率仍有限。[Figure 3、附录 C]

4.2 固定锚点、交互写入与容量需要分别验证

锚点有平均收益，也会干扰部分任务。 五任务平均从 37.6% 提高到 50.0%，但 Block Ranking 从 32.0% 降到 22.0%。作者认为这一任务更依赖持续变化的尝试历史，固定初始参考帮助较小。把初始帧直接放进 prefix 也不等于锚点：Put Back 上该变体为 22.0%，无锚点为 34.0%，提出的锚点路径为 40.0%。这些结果提示读取方式重要，但仅凭一个任务还不能断言直接拼接初始帧总会降低性能。[§6、附录 D.3]

动作与后续视觉互补。 Put Back、Rearrange、Battery 三任务的写入内容消融平均值为：

写入内容 平均成功率
仅动作 34.7%
仅后续视觉 42.7%
后续视觉＋动作 46.7%

这组逐任务数值与 Table 1 的无锚点配置一致，不能与完整五任务的 50.0% 直接比较。它支持动作摘要提供额外信息，尚未证明动作顺序被完整保留。

固定容量仍然受容量限制。 无锚点版本在 Put Back 和 Rearrange 两任务上， r=32,64,128 的平均成功率依次为 27.0%、42.0%、55.0%。矩阵标量数按 r2 增长，从 32 到 128 是 16 倍状态大小。[附录 D.2]

因此，与显式 token 记忆比较时应匹配总状态预算，不能只拿“一个 memory token”和“八个记忆 token”的数量比较。一个读取 token 背后可能是逐层矩阵和几十个锚点 token。

4.3 好的分析应定位到需要历史的决策点

作者人工标注相同种子的 50 对 rollout，区分前面的动作执行与后面的历史依赖决策。[附录 E]

任务 需要保留的信息 行为证据
Put Back 初始垫子位置 错误返回由 Stateless 的 37/50 降到 13/50；前面的移动和按键两者都完成
Rearrange 哪块积木最初在垫子上 MemBodied 在 50 次中都选对；Stateless 在实际移动积木的 40 次中选错 20 次
Swap 三次转移已完成几次 提前宣布完成由 41/50 降到 19/50
Battery 瞬时反馈消失前的失败结果 双电池放好后的尝试中，MemBodied 通常再试一次成功，Stateless 中位数还需四次
Ranking 新排列是否已验证 完成排列后，MemBodied 在 35/38 次中测试，Stateless 为 14/40

这些分母对应不同阶段，不能与总体成功率混算。它们比只有总分更有帮助：模型的差异集中在过去信息已不可见的地方，而不是所有早期运动阶段都一起提升。

但 Ranking 的长程搜索仍然困难。拒绝一个排列后，MemBodied 只有 10/28 次继续构建并验证新排列，仍会重复旧尝试或在重新排列时失败。这说明“记得立刻验证”和“记住多轮搜索结果”是不同难度。

对我的实验，可以沿用这种分阶段记录，再增加匹配当前观察与动作条件的历史干预，检查替换或删除历史是否确实改变未来预测和动作选择。

NativeMEM 的周期包含两次策略查询之间的历史编码及后续策略计算，MemBodied 包含当前图像编码、记忆读写与动作生成。这个设置下延迟降低 91.9%，显存降低约 9.5%。40M 是新增参数量，不是回合状态大小；该比较也不能证明相对 Stateless 几乎没有开销。

跨回合实验也值得留意：锚点始终正常重建，只让关联矩阵跨回合保留，平均成功率从 50.0% 降至 36.8%。模型原本按回合 reset 训练，结果不支持直接持续累积同一个状态，更不能视为已经学会跨回合知识迁移。[附录 D.4]

4.5 与我当前方案重合在哪里？

根据目前的研究笔记，以下设计已经与本文有明确重合：固定容量的持续状态、独立初始参考、动作与后续观察参与更新、门控读写，以及后续动作损失回传到早期写入。因此，这些不能再单独作为核心原创贡献来表述。

更具体的区别是：

方面 MemBodied 我当前笔记中的方案
动态状态 动作专家逐层关联矩阵 显式 key/value 证据条目
内容管理 门控 delta rule 区分修订、新绑定或替换，以及不写入
初始参考 每相机 16 个池化空间 token 单个任务条件摘要 token
策略接口 动作专家 suffix memory token VLM prefix 前置记忆
训练监督 动作损失 动作损失加延迟 JEPA 损失
预测路径 无独立预测分支 动作条件 predictor 与冻结 teacher
研究重点 记录与检索交互，改善历史依赖控制 后果监督怎样训练有限记忆的保留与修订

这张表描述研究方案的区别，不代表这些设计已经实验验证。尤其“初始锚点＋动态记忆”已经重合，单纯换接入位置或把矩阵换成 token，仍需要说明解决了什么具体问题。

4.6 我最需要补的增量证据

当前更值得追问的是：在相同记忆结构与容量下，动作条件的延迟视觉后果监督，能否让模型保留当前不可见的证据，并在状态改变后正确修订，从而改善后续决策？

我认为至少需要以下对照：

  1. 相同记忆，有／无 JEPA。 固定结构和状态预算，排除收益只来自增加记忆。
  2. 隔离 JEPA 到动态记忆的梯度。 检查预测损失是否训练了记忆，而不只是改善当前上下文。
  3. 匹配当前观察和动作条件的历史干预。 替换、删除或打乱相关历史，检查预测与决策是否同时受影响。
  4. 初始帧之后才出现的线索。 避免结果主要来自固定锚点。
  5. 线索后来发生变化。 检查能否修订旧事实，而非一直保留早期内容。
  6. 相同状态预算的关联矩阵对照。 将矩阵、显式条目、初始锚点和部署缓存的存储分别列出。

MemBodied 已经证明后续动作损失可以训练先前写入。我的工作需要进一步说明，增加延迟后果监督后，记忆具体学会了哪些保留与修订行为，以及这些变化怎样影响动作。

局限性&未来工作：

关联干扰与长程搜索仍未解决。 delta rule 可以修正一个 key 对应的关联，但相近 key 之间会互相影响。较多更新之后，多个历史绑定能保留多久、何时被覆盖，仍缺少直接验证。可以结合可控线索冲突、重复尝试与延迟决策任务研究这一点。

动作摘要缺少顺序，执行对齐也需检查。 动作求和压缩了时序；LIBERO 附录还使用完整预测 chunk 配对后续观察，其中一部分未实际执行。未来可以比较实际执行动作序列、时序动作编码与求和摘要，单独衡量记忆更新是否受影响。

固定初始锚点会带来任务相关的取舍。 它提高平均结果，却降低 Block Ranking 表现。后续应区分初始布局仍有效、线索在回合中新增，以及初始信息已经过时的任务，研究何时读取固定参考、何时应依赖更新后的证据。

评测覆盖和真机可靠性有限。 主要记忆评测是五个 RMBench 任务，真机只有三个任务、每模型每任务 20 次，完整模型仅 16/60 成功。更广泛的遮挡、证据绑定、变化修订和跨任务测试仍然必要。

部分比较不能独立归因。 π₀.₅ 基线引用已发表结果，NativeMEM 有额外分阶段训练，层次变体同时改变状态与读出。后续需要匹配结构、数据与计算预算的对照，并在相同失败状态或相同历史条件下分析。

行为分析尚不能完全解释记忆内容。 阶段错误分析定位了历史依赖决策，但没有直接证明矩阵中保存的具体事实。可通过锚点替换、记忆交换、选择性擦除和梯度隔离，检验模型是否读取了正确证据。

回合内固定状态不等于跨回合长期学习。 本文训练与主实验都按回合重置，直接跨回合保留矩阵反而降低平均结果。若要支持更长期部署，需要另行设计上下文边界、遗忘与知识迁移机制。
