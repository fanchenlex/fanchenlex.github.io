StateMem | Under Review

Posted 2026-09-16Updated 2026-09-22publications6 minutes read (About 856 words)0 visits

StateMem：通过单状态残差记忆持续保留任务历史信息，并利用预测误差进行自适应前缀路由，在提升记忆依赖任务性能的同时减少 VLA 推理中的冗余 VLM 计算。

Paper Information

  • 作者： Wenzhuo Li, Qiongfeng Shi, Yi Zhou
  • 版本： arXiv 预印本，2026 年 9月 19 日
  • 论文： PDF
  • 在线阅读： 全文

Research Problem

现有 VLA 策略主要依赖当前观测或有限的历史帧，
当任务需要利用早期交互中已经不可见的信息时，容易丢失关键任务状态。

多帧历史输入会带来额外的注意力计算、KV Cache 和内存开销，
而外部 Memory Bank 则需要显式的存储、检索和整合机制。

与此同时，连续推理过程中相邻观测往往高度相似，
每次都重新计算完整的 VLM Prefix 也会产生大量冗余计算。

Method

StateMem 用一个持久化的单记忆状态表示任务历史。

首先从当前视觉输入中提取感知特征，并结合图像-语言前缀中的认知特征初始化单个 memory token。
随后利用预测器从上一时刻的 memory 预测当前感知特征，
将预测误差通过低秩残差映射写回 memory，实现持续的历史信息更新。

在推理阶段，StateMem 进一步利用缓存锚点对应的预测误差判断当前观测与缓存状态的一致性：
误差较小时复用 VLM Prefix，误差较大时重新刷新 Prefix。
缓存复用期间，Fast Correction 分支利用当前 memory、感知特征和本体状态的变化补偿陈旧的 Prefix 特征。

此外，训练免费的在线控制器通过 EMA 统计和周期性的动作审计动态调整路由阈值，从而适应不同交互阶段的状态变化。

Results

以下数据来自论文中的 LIBERO、RoboMemArena 和真实机器人实验。

基准 方法 主要结果 推理效率
LIBERO π0.5 96.9% Avg. SR 100% Prefix Refresh
LIBERO StateMem 97.6% Avg. SR 79.75% Prefix Refresh
RoboMemArena π0.5 21.5% TSR / 38.7% CSR —
RoboMemArena StateMem 26.8% TSR / 44.4% CSR —
Real World π0.5 44% Avg. SR —
Real World StateMem 65% Avg. SR —

在 LIBERO 上，StateMem 达到 97.6% 的平均成功率，
相比 π0.5 的 96.9% 提升 0.7 个百分点；
同时将平均 VLM Prefix 刷新率从 100.00% 降至 79.75%。

在 RoboMemArena 上，StateMem 的平均 TSR 和 CSR 分别达到 26.8% 和 44.4%。
其中 Occlusion 类别达到 21.8% TSR 和 44.3% CSR，体现了持久化记忆对遮挡场景的帮助。

在真实机器人实验中，StateMem 在四个通用操作任务和两个记忆依赖任务上取得 65% 的平均成功率，
相比 π0.5 的 44% 提升 21 个百分点。

Limitation

单个 memory token 对复杂历史事件的表达能力仍然有限，
对于需要同时保存多个细粒度历史信息的任务可能不足。

此外，目前实验覆盖的机器人形态、传感模态和任务时间跨度仍然有限，
推理加速效果也依赖实际的 Prefix 刷新率：
当刷新率较高时，路由判断和动作审计带来的额外开销可能抵消部分计算收益。
